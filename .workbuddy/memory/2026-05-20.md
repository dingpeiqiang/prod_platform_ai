## 条件分支节点值加载不全问题修复

### 问题描述
用户反馈：资费备案公示工作流 JSON 配置中，条件分支节点的值加载不全。

### 根本原因
**前后端条件分支数据格式不兼容**：

| 组件 | 数据结构 |
|------|----------|
| 前端 ConditionNode.vue | `branches[].conditions[{variable, operator, valueType, value}]` |
| 后端 ConditionNodeExecutor | 期望 `{leftType, leftValue, operator, rightType, rightValue}` |

执行器代码期望的字段名和实际 JSON 配置中的字段名不匹配，导致条件配置无法正确加载。

### 修改内容

#### 1. workflow_executor.py - ConditionNodeExecutor 重构

新增方法：
- `_evaluate_branches()`: 评估 branches 格式的条件（前端 Vue Flow 风格）
- `_evaluate_legacy_format()`: 兼容旧格式的评估

修改 `execute()` 方法逻辑：
- 优先检测 `branches` 格式
- 支持 `branch_0`, `branch_1` 等多分支输出边
- 同时兼容旧格式的 `true/false` 输出边

#### 2. lcel_converter.py - 条件处理逻辑重构

新增方法：
- `_handle_condition_branches()`: 处理 branches 格式的条件节点
- `_handle_condition_legacy()`: 处理旧格式的条件节点
- `_evaluate_single_condition()`: 单个条件表达式评估

修改方法：
- `_handle_condition()`: 路由到对应的处理方法
- `_build_condition_chain()`: 支持多分支条件链构建
- `_build_branches_condition_chain()`: 新增多分支链构建方法

### 验证结果
- `workflow_executor.py` 语法检查通过
- `lcel_converter.py` 语法检查通过
- 工作流配置中的边定义正确（`sourceHandle: "branch_0"` 和 `"branch_1"`）

## 工作流编辑器锚点模式切换 - 节点布局同步调整

### 问题
用户反馈：切换锚点模式（垂直/水平布局）时，节点的排版没有同步调整。

### 根本原因
1. `toggleAnchorMode` 只更新了 `element.data.anchorMode`，没有重新计算节点位置
2. VueFlow 的 `direction` 属性没有设置，无法控制边的路径方向
3. `ConditionNode.vue` 缺少对 `isVertical`（锚点模式）的监听

### 修改内容

#### 1. ConditionNode.vue - 添加 isVertical 监听
```javascript
// 监听锚点模式变化（切换垂直/水平布局时重新计算 Handle 位置）
watch(isVertical, () => {
  nextTick(() => updateHandlePositions());
});
```

#### 2. LangChainEditor.vue - 三处修改

**a) 导入 autoLayoutNodes**
```javascript
import { debounce, validateWorkflow, alignNodes, distributeNodes, autoLayoutNodes } from './utils/editorUtils';
```

**b) 添加 vueFlowDirection 状态**
```javascript
const vueFlowDirection = ref('TB'); // VueFlow 布局方向：TB（垂直）或 LR（水平）
```

**c) VueFlow 组件绑定 direction**
```html
<VueFlow
  ...
  :direction="vueFlowDirection"
  ...
>
```

**d) 重写 toggleAnchorMode 函数 - 实现节点位置交换**
```javascript
const toggleAnchorMode = () => {
  const newMode = currentAnchorMode.value === 'vertical' ? 'horizontal' : 'vertical';
  const newDirection = newMode === 'vertical' ? 'TB' : 'LR';
  currentAnchorMode.value = newMode;
  vueFlowDirection.value = newDirection;

  const nodes = elements.value.filter(el => !el.source && !el.target);

  if (nodes.length > 0) {
    let minX = Infinity, maxX = -Infinity;
    let minY = Infinity, maxY = -Infinity;
    nodes.forEach(node => {
      minX = Math.min(minX, node.position.x);
      maxX = Math.max(maxX, node.position.x + (node.width || 180));
      minY = Math.min(minY, node.position.y);
      maxY = Math.max(maxY, node.position.y + (node.height || 80));
    });

    const MARGIN = 100;
    nodes.forEach(node => {
      const newX = node.position.y - minY + MARGIN;
      const newY = node.position.x - minX + MARGIN;
      node.position.x = newX;
      node.position.y = newY;
      node.data.anchorMode = newMode;
    });
  }

  elements.value = [...elements.value];
  hasChanges.value = true;
};
```

### 效果
当用户点击锚点模式切换按钮时：
1. 节点的 Handle 位置会根据布局方向自动调整（通过 useNodeAnchorMode hook）
2. 所有节点的位置会交换 x/y 坐标（实现布局旋转 90 度）
3. VueFlow 的 direction 会改变（影响边的路径显示）
4. ConditionNode 的分支 Handle 位置会重新计算

## UserInputNode 优化 - 支持水平和垂直布局

### 修改内容

#### 1. 提取 isVertical 状态

```javascript
const { targetPosition, sourcePosition, isVertical } = useNodeAnchorMode(props);
```

#### 2. 添加 Handle 动态样式绑定

```html
  :style="isVertical ? { left: getHandleLeft(0) + '%' } : { top: getHandleTop(0) + '%' }"

```

#### 3. 添加 Handle 位置计算方法
```javascript
// 计算 Handle 的垂直位置百分比（水平布局时用于 source handle 的 top 定位）
const getHandleTop = (index) => {
  return 50; // 单个 handle 居中
};

// 计算 Handle 的水平位置百分比（垂直布局时用于 source handle 的 left 定位）
const getHandleLeft = (index) => {
  return 50; // 单个 handle 居中
};
```

#### 4. 添加 CSS 水平和垂直布局支持
```css
/* 水平布局时 Source Handle 位置调整 - 居中垂直定位 */
:deep(.vue-flow--horizontal) .user-input-node .vue-flow__handle[type="source"] {
  top: 50%;
  transform: translateY(-50%);
}

/* 垂直布局时 Source Handle 位置调整 - 居中水平定位 */
:deep(.vue-flow--vertical) .user-input-node .vue-flow__handle[type="source"] {
  left: 50%;
  transform: translateX(-50%);
}

/* 水平布局时 Target Handle 位置微调 */
:deep(.vue-flow--horizontal) .user-input-node .vue-flow__handle[type="target"] {
  top: 50%;
  transform: translateY(-50%);
}

/* 垂直布局时 Target Handle 保持默认 */
:deep(.vue-flow--vertical) .user-input-node .vue-flow__handle[type="target"] {
  top: 0;
  transform: translateX(-50%);
}
```

### 效果
UserInputNode 现在支持水平和垂直两种布局模式，与 ConditionNode 保持一致的处理方式。

## 工作流库加载 - 条件分支配置参数为空问题修复

### 问题描述
用户反馈：资费备案公示工作流加载到工作流编辑器后，条件分支配置参数为空。

### 根本原因
**WorkflowLibrary 加载工作流时使用了列表接口返回的不完整数据**：

1. `WorkflowService.list_workflows()` 调用 `_load_workflow_from_file(workflow_code, include_data=False)`
2. 列表接口返回的数据**不包含** `workflowData` 字段
3. `WorkflowLibrary.loadWorkflow()` 直接 emit 了这个不完整的数据
4. `handleLoadFromLibrary` 尝试从 `workflow.workflowData.nodes` 读取，结果为空数组

### 修复方案
修改 `WorkflowLibrary.vue` 的 `loadWorkflow` 函数为异步函数，加载时先调用 `workflowApi.workflowApi.get(workflow.workflowCode)` 获取完整数据：

```javascript
const loadWorkflow = async (workflow) => {
  try {
    // 获取完整的工作流数据（包括 workflowData）
    const result = await workflowApi.workflowApi.get(workflow.workflowCode)
    if (result.success && result.data) {
      emit('load-workflow', result.data)
      ElMessage.success(`已加载工作流: ${workflow.workflowName}`)
    } else {
      // 如果获取失败，尝试使用本地数据（兼容没有后端的情况）
      emit('load-workflow', workflow)
      ElMessage.warning(`从缓存加载工作流: ${workflow.workflowName}`)
    }
  } catch (error) {
    console.error('加载工作流失败:', error)
    // 获取失败时使用本地数据作为兜底
    emit('load-workflow', workflow)
    ElMessage.warning(`从缓存加载工作流: ${workflow.workflowName}`)
  }
}
```
