### 任务 #4：迁移意图系统（intent/handlers + registry + context）

**新建文件**（12 个，`com.sitech.prodai.intent` 包）：

核心基础设施：
- `StreamStats.java` — 流式统计（对齐 Python StreamStats + chat_stream 扩展字段）
- `IntentContext.java` — 上下文数据袋（对齐 Python @dataclass IntentContext）
- `BaseIntentHandler.java` — 处理器接口（`Flux<Map<String, Object>> handle(IntentContext)`）
- `SseUtils.java` — SSE 工具（thinking/askUser/reasoning/intentEvent/doneEvent/mergeFieldRecommendations）
- `IntentHandlerRegistry.java` — Spring @Component 注册器（自动注入 List<BaseIntentHandler>，未注册意图降级到 ChatHandler）

7 个处理器：
- `ChatHandler.java` ("chat") — LLM 流式回复 + 降级处理器
- `FormHandler.java` ("form") — AI 字段推断 + 推荐引擎批量推荐 + 合并推荐
- `FormUpdateHandler.java` ("form_update") — 增量字段更新
- `DeleteFormHandler.java` ("delete_form") — 删除表单（OntologyService 返回"不支持"）
- `ConfigureHandler.java` ("configure") — AI 对话生成新表单配置
- `ManageHistoryHandler.java` ("manage_history") — 4 种子操作（analyze/import/query/export/status）
- `ValidationHandler.java` ("validate") — 规则引擎 + LLM 双重校验 + 结构化错误表

**关键设计**：
- Python `async for yield SSE帧` → Java `Flux<Map<String, Object>>`（Reactor）
- Python `await loop.run_in_executor` → Java `Flux.fromCallable().subscribeOn(Schedulers.boundedElastic())`
- Python `@intent_handler` 装饰器注册 → Spring 自动注入 `List<BaseIntentHandler>`
- Python 单例 `get_intent_registry()` → Spring `@Component`（单例 by default）
- ChatHandler 实现 `IntentHandlerRegistry.ChatHandlerFallback` 接口作为降级处理器

**依赖服务映射**：
- `ai_inference_service.infer_fields()` → `LlmService.completePrompt()` + JSON 解析
- `AdminService.delete_ontology()` → `OntologyService.deleteOntology()`（返回"不支持"）
- `AdminService.chat()` → `LlmService.complete()` + systemPrompt
- `history_ai_service.*` → `HistoryService.getRecommendValues()`
- `ValidationSkill.validate_*` → `ValidationService.validateForm()` + `LlmService.completePrompt()`
