# 2026-05-22 工作日记

## 工作流编辑器变量列表修复

### 问题
工作流编辑器"引用变量列表"的级联选择器中，第一列节点列表显示的标签不正确，有时会显示变量名（如 "output"）而不是节点类型标签（如 "LLM节点"）。

### 根因
在 `cascaderOptions` 计算属性中，尝试从 `variable.name` 提取节点标签：
```javascript
const namePart = variable.name.split('(')[0].trim();
if (namePart && !namePart.includes('输出') && !namePart.includes('入参')) {
  nodeLabel = namePart;
}
```
当变量名没有括号时（如 "output"），这段代码错误地将变量名当作节点标签。

### 修复
修改了三个文件，统一使用 `getNodeLabelById(variable.nodeType)` 根据节点类型获取标签：
- `frontend/src/components/workflow-editor/nodes/LlmNode.vue`
- `frontend/src/components/workflow-editor/nodes/PromptNode.vue`
- `frontend/src/components/workflow-editor/nodes/ConditionNode.vue`

修复后的逻辑：
```javascript
if (variable.nodeType === 'start') {
  nodeLabel = '开始节点';
} else if (variable.nodeType) {
  nodeLabel = getNodeLabelById(variable.nodeType);
}
```
