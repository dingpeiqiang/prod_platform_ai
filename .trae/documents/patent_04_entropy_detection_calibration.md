# 专利申请书

## 一、发明名称

一种AI输出的多维度熵检测与自适应置信度校准方法

---

## 二、所属技术领域

本发明涉及计算机技术领域，特别是涉及人工智能输出的质量评估与校准技术，具体涉及一种对AI模型输出进行多维度熵检测并自适应校准置信度的方法。

---

## 三、背景技术

随着大语言模型（LLM）在各类业务场景中的广泛应用，AI输出质量的控制和评估已成为制约其实际落地的关键技术瓶颈。现有的AI输出质量评估方法主要存在以下问题和缺陷：

**1. AI输出的不确定性难以量化**

大语言模型的输出具有天然的不确定性：同一次输入在不同参数下可能产生不同的输出；同一模型在多次调用中可能产生不一致的结果。现有技术主要通过单一的置信度评分来表征这种不确定性，但存在以下不足：
- 置信度评分通常由模型自身生成，存在系统性的过度自信偏差
- 单一评分无法反映输出在不同维度上的质量差异
- 缺乏统一的不确定性分级标准

**2. 现有评估维度单一**

传统的AI输出质量评估主要关注单一方面：
- 仅检查输出格式是否规范（如JSON解析是否成功），忽略内容完整性
- 仅检查文本长度是否达标，忽略语义一致性和主题相关性
- 仅进行一次性的质量检查，忽略多次输出的一致性
- 缺乏对输出中占位符、不完整句子、自相矛盾等质量缺陷的系统性检测

**3. 模型置信度校准不足**

大语言模型在输出概率分布时，往往存在严重的校准不足问题。现有校准方法主要针对传统机器学习模型的softmax输出，对于生成式AI模型的置信度校准效果不理想：
- 温度缩放方法过于简单，无法处理异构数据分布的校准需求
- Platt缩放需要大量标注数据，在线场景下难以实时更新
- 缺乏自适应的方法选择机制，无法根据数据特征自动选择最优校准策略

**4. 不确定性处理缺乏系统性策略**

当检测到AI输出存在不确定性时，现有系统通常采取简单的"重试"或"直接返回"的策略，缺乏系统化的分级处理机制：
- 不能根据不确定性级别选择差异化策略
- 缺乏多样性采样、外部知识查询、人工审核等策略的组合应用
- 缺少降级处理机制，在高不确定性场景下无法返回安全的保守结果

**5. 现有技术中的核心矛盾**

现有技术在AI输出质量评估中面临一个根本矛盾：**评估的全面性与实时性之间的权衡**。越全面的质量评估需要越多维度的检测，导致响应延迟增加；而追求实时性的简单检测又无法保证评估的全面性和准确性。

综上所述，现有技术中缺乏一种通过多维度熵检测、置信度自适应校准和分级不确定性处理相结合，实现对AI输出质量全面、实时、可解释的评估与保障方法。

---

## 四、目的

本发明旨在解决现有技术中存在的如下技术问题：

1. **AI输出不确定性的多维量化问题**：解决传统单一置信度评分无法全面反映AI输出质量的问题，构建多维度熵检测体系
2. **不同维度检测的融合评估问题**：解决多维度检测结果如何融合为统一的总体评估，并依据评估结果进行分级决策的技术问题
3. **置信度系统性偏差的校准问题**：解决大语言模型输出置信度与实际准确率之间的系统性偏差问题，实现置信度的自适应校准
4. **校准方法的自动选择问题**：解决面对不同数据分布特征时，如何自动选择最优校准策略的技术问题
5. **不确定性的分级处理问题**：解决如何根据不确定性级别，采取差异化的解决策略（重试、多样性采样、外部查询、人工审核、降级处理等）的技术问题

本发明的目的在于提供一种AI输出的多维度熵检测与自适应置信度校准方法，通过"四维熵检测→加权融合评估→自适应置信度校准→分级不确定性处理"的完整链路，实现对AI输出质量的全面评估和智能保障。

## 五、技术方案

### 5.1 设计思路

本发明的核心设计思路是：**将信息论中的熵（Entropy）概念引入AI输出质量的评估体系**，从多个维度量化AI输出的不确定性，并通过加权融合实现总体评估。在评估的基础上，对置信度进行自适应校准，最终根据校准后的不确定级别采取差异化的处理策略。

```
四维熵检测        加权融合        自适应校准        分级处理
    ↓                ↓               ↓               ↓
一致性熵 →┐
格式熵   →├─ 加权平均 → 总体熵 → 置信度校准 → 分级决策 → 处理结果
内容熵   →├─ 五级分类                        ↓
语义熵   →┘                            重试/多样性/外部/人工/降级
```

### 5.3 技术方法步骤

#### 步骤一：四维熵检测

对AI输出从四个维度分别计算熵值，每个维度的熵值范围为[0, 1]，值越高表示不确定性越大。

**维度1：一致性熵（Consistency Entropy）**

评估AI模型多次输出之间的一致性程度。当相同或相似输入产生不同输出时，一致性熵升高。

检测方法：
- 收集同一输入下的多次输出列表 `outputs = [o1, o2, ..., on]`
- 对每对输出计算字符集合相似度：`similarity = len(set(s1) & set(s2)) / len(set(s1) | set(s2))`
- 计算所有输出对间的平均相似度 `avg_similarity`
- 一致性熵 = 1 - avg_similarity

特征：
- 单次输出或两次完全相同的输出 → 一致性熵 = 0.0
- 两次完全不同输出 → 一致性熵 = 1.0
- N次输出时，计算所有两两组合的相似度均值

**维度2：格式熵（Format Entropy）**

评估AI输出在格式层面的规范性。支持多种格式类型的检测：

（a）**JSON格式熵检测**：
- 是否以 `{` 或 `[` 开头（缺失 +0.3）
- 能否被 `json.loads` 成功解析（失败 +0.4）
- 是否包含键值对标记 `:` 和 `,`（缺失 +0.2）

（b）**XML格式熵检测**：
- 是否以 `<` 开头（缺失 +0.3）
- 开始标签与闭合标签数量是否匹配（不匹配 +0.4）

（c）**Markdown格式熵检测**：
- 是否包含标题标记（`#`）、代码块（```）、列表（`-`/`*`）
- 缺乏格式元素 → 熵上升
- 多种格式元素混合 → 熵下降（格式丰富）

（d）**通用格式熵检测**（无特定格式要求时）：
- 多行文本的行首缩进一致性
- 异常缩进比例导致熵上升

**维度3：内容熵（Content Entropy）**

评估AI输出的内容完整性。从以下子维度检测：

（a）**长度检测**：文本长度<10个字符 → +0.3（可能为无效输出）

（b）**占位符检测**：检测输出中是否包含未填充的占位符，如 `xxx`、`...`、`TODO`、`TBD`、`XXXX`
- 任何占位符出现 → +0.2

（c）**必需字段检测**：根据 `required_fields` 列表，逐一检查每个必需字段是否在输出中出现
- 缺失的字段比例 → +0.3 × (missing/total)

（d）**句子完整性检测**：通过标点符号分割句子，检测是否以连接词开头的不完整句子
- 不完整句子比例 → +0.2 × min(1.0, incomplete/max_output_length)

**维度4：语义熵（Semantic Entropy）**

评估AI输出在语义层面的合理性。从以下子维度检测：

（a）**主题偏离检测**：计算输出文本与期望主题 `expected_topic` 的词语重叠度
- 相似度 < 0.3 → 主题严重偏离，+0.4

（b）**禁止词检测**：检查输出中是否包含 `forbidden_words` 列表中的词汇
- 任何禁止词出现 → +0.5

（c）**自相矛盾检测**：通过预设的肯定/否定矛盾对列表（如"是/不是"、"有/没有"、"可以/不能"、"对/错"、"真/假"），检测同一句子中是否同时包含肯定词和否定词
- 每对矛盾在同一个句子中出现 → +0.2

（d）**重复检测**：使用3-gram（三元组）检测输出中的重复程度
- 重复率 = 1 - (唯一n-gram数 / 总n-gram数)
- 重复率 > 0.3 → +0.3

#### 步骤二：加权融合与分级评估

将四个维度的熵值通过加权平均计算总体熵，并据此进行五级分类。

**加权融合公式：**

```
overall_entropy = consistency_entropy × 0.3 
                + format_entropy × 0.2 
                + content_entropy × 0.3 
                + semantic_entropy × 0.2
```

权重设计说明：
- 一致性熵和内容熵各占0.3：这两项直接影响输出的可用性
- 格式熵和语义熵各占0.2：这两项重要但可容忍度相对较高

**五级分类标准：**

| 总体熵范围 | 熵级别 | 含义 | 处理策略 |
|:---------:|:------|:----|:---------|
| 0.0 - 0.2 | VERY_LOW | 极低不确定性 | 直接接受 |
| 0.2 - 0.4 | LOW | 低不确定性 | 直接接受 |
| 0.4 - 0.6 | MEDIUM | 中等不确定性 | 尝试自动解决（重试） |
| 0.6 - 0.8 | HIGH | 高不确定性 | 强力干预（多样性+外部） |
| 0.8 - 1.0 | VERY_HIGH | 极高不确定性 | 人工审核或降级 |

**自适应阈值调整：**

基于最近10次检测结果，动态调整检测阈值以避免过于严格或宽松：
- 监控近10次结果中高熵（HIGH/VERY_HIGH）的比例
- 如果高熵比例 > 50%，说明检测过于严格，所有阈值 +0.05（放宽）
- 如果高熵比例 < 10%，说明检测可能过于宽松，所有阈值 -0.05（收紧）
- 阈值范围限制在[0.0, 1.0]

#### 步骤三：置信度自适应校准

对检测得到的置信度进行校准，消除模型系统性的过度自信或置信不足偏差。

**校准方法池：**

（a）**温度缩放（Temperature Scaling）**

在logit空间对置信度进行缩放：
```
logits = ln(confidence / (1 - confidence))
scaled_logits = logits / temperature
calibrated = 1 / (1 + e^(-scaled_logits))
```
- temperature > 1：降低置信度（校正过度自信）
- temperature < 1：提高置信度（校正置信不足）
- 通过交叉熵损失优化训练得到最优温度

（b）**Platt缩放（Platt Scaling）**

在logit空间进行线性变换：
```
scaled_logits = a × logits + b
calibrated = 1 / (1 + e^(-scaled_logits))
```
- 参数a、b通过最小化负对数似然训练得到
- 对a和b进行网格搜索（a∈[0.5,2.0]，b∈[-1.0,1.0]），选最优组合

（c）**Beta校准（Beta Calibration）**

使用Beta分布的参数化校准：
```
calibrated = β_a × confidence + (1 - β_b) × confidence²
```
- β_a = 0.5 + 0.5 × avg_correct_confidence
- β_b = 0.5 + 0.5 × (1 - avg_wrong_confidence)

（d）**直方图校准（Histogram Calibration）**

将置信度分箱，每箱内用实际准确率代替原始置信度：
- 将[0, 1]区间等分为N个bins（默认N=10）
- 统计每个bin中的样本数量和正确样本数量
- 校准后的置信度 = 该bin内正确的样本数 / 总样本数

**自动方法选择（AUTO模式）：**

基于训练数据的统计分析自动选择最优方法：
1. 如果训练样本数 < 20：使用温度缩放（简单可靠）
2. 计算置信度方差：
   - 方差 < 0.01：置信度集中，使用温度缩放
   - 方差 ≥ 0.01：置信度分散，使用直方图校准
3. 选择后通过网格搜索确定最优参数

**在线更新机制：**

`update(confidence, is_correct)` 方法支持在每次预测后增量更新校准器：
- 将新的 (置信度, 正确性) 样本加入训练数据
- 限制训练数据最多1000条（FIFO策略）
- 每积累50个新样本自动重新训练一次

#### 步骤四：分级不确定性处理

根据校准后的不确定性级别，选择差异化的处理策略。

**不确定性级别的判定标准：**

| 校准后置信度 | 不确定性级别 | 处理策略 |
|:----------:|:----------:|:---------|
| ≥ 0.9 | NONE | 直接接受 |
| 0.7 - 0.9 | LOW | 直接接受 |
| 0.4 - 0.7 | MEDIUM | 重试（自动解决） |
| 0.2 - 0.4 | HIGH | 多样性采样+外部查询 |
| < 0.2 | VERY_HIGH | 人工审核+降级处理 |

**策略定义：**

（a）**重试策略（RETRY）**：重新调用AI模型生成新的输出
- 配置：最大重试3次，初始延迟0.5秒，指数退避，随机抖动
- 适用场景：中等不确定性，临时性波动

（b）**多样性采样策略（DIVERSE_SAMPLING）**：使用不同参数（temperature、top_p）进行多次采样，选择最一致的输出
- 采样次数：3次
- 选择方法：计算输出间的相似度，选择与多数输出相似度最高的结果
- 适用场景：高不确定性，结果不稳定

（c）**外部查询策略（EXTERNAL_LOOKUP）**：从外部知识库或API查询来验证和补充输出
- 通过注册的 `external_lookup` 函数执行查询
- 适用场景：知识不足导致的认知不确定性

（d）**人工审核策略（HUMAN_REVIEW）**：将输出发送给人工审核人员进行判断
- 通过注册的 `human_review_callback` 回调函数触发
- 适用场景：极高不确定性，自动方法无法解决的复杂情况

（e）**降级处理策略（DEGRADATION）**：返回安全的保守结果
- 返回结构化降级响应：`{status: "uncertain", message: "输出存在不确定性，请人工审核"}`
- 适用场景：所有自动策略均失败时的最终兜底

**策略组合执行流程：**

对于中等不确定性（MEDIUM）：
```
1. 尝试重试策略（1次）
   → 成功 → 返回
   → 失败 → 标记为需要人工审核
```

对于高不确定性（HIGH/VERY_HIGH）：
```
1. 尝试多样性采样策略（3次采样，选最一致输出）
   → 成功且置信度提升至阈值以上 → 返回
   → 失败 → 继续
2. 尝试外部查询策略（如果有注册external_lookup）
   → 成功 → 返回（置信度提至0.8）
   → 失败或无查询函数 → 继续
3. 尝试人工审核（如果有注册human_review_callback）
   → 成功 → 返回审核结果
   → 失败或无人审核 → 继续
4. 使用降级处理 → 返回安全结果
```

### 5.4 算法描述

**算法1：多维度熵检测与分级评估算法**

```
输入：output（AI输出文本）, outputs（可选，多次输出列表）
      expected_format（可选，期望格式）, required_fields（可选，必需字段列表）
      expected_topic（可选，期望主题）, forbidden_words（可选，禁止词列表）
输出：EntropyResult（熵检测结果）

// 阈值配置
thresholds = {
    consistency: 0.3, format: 0.4, content: 0.3, semantic: 0.4, overall: 0.5
}

// 1. 一致性熵检测
if outputs 存在 且 len(outputs) > 1:
    consistency_entropy = 0
    for i in range(len(outputs)):
        for j in range(i+1, len(outputs)):
            set_i = set(outputs[i]), set_j = set(outputs[j])
            similarity = len(set_i & set_j) / max(len(set_i | set_j), 1)
            consistency_entropy += (1 - similarity)
    consistency_entropy /= count_of_pairs
else:
    consistency_entropy = 0.0

// 2. 格式熵检测
format_entropy = 0
if expected_format == "json":
    if not output.strip().startswith(('{', '[')):
        format_entropy += 0.3
    if json.loads(output) 失败:
        format_entropy += 0.4
    if ':' not in output and ',' not in output:
        format_entropy += 0.2
elif expected_format == "xml":
    if not output.strip().startswith('<'):
        format_entropy += 0.3
    if 开始标签数 != 闭合标签数 + 自闭合标签数:
        format_entropy += 0.4
else:
    format_entropy = detect_generic_format(output)
format_entropy = min(1.0, format_entropy)

// 3. 内容熵检测
content_entropy = 0
if len(output) < 10:
    content_entropy += 0.3
if 包含占位符("xxx", "TODO", "TBD", ...):
    content_entropy += 0.2
if required_fields:
    missing = 0
    for field in required_fields:
        if field 不在 output 中:
            missing += 1
    content_entropy += 0.3 × (missing / len(required_fields))
content_entropy = min(1.0, content_entropy)

// 4. 语义熵检测
semantic_entropy = 0
if expected_topic:
    topic_similarity = 计算主题相似度(output, expected_topic)
    if topic_similarity < 0.3:
        semantic_entropy += 0.4
if forbidden_words:
    for word in forbidden_words:
        if word 在 output 中:
            semantic_entropy += 0.5
            break
contradictions = 检测自相矛盾(output, 矛盾对列表)
semantic_entropy += contradictions × 0.2
repetition_ratio = 检测重复度(output)
if repetition_ratio > 0.3:
    semantic_entropy += 0.3
semantic_entropy = min(1.0, semantic_entropy)

// 5. 计算总体熵
overall_entropy = consistency_entropy × 0.3
                 + format_entropy × 0.2
                 + content_entropy × 0.3
                 + semantic_entropy × 0.2

// 6. 确定熵级别
if overall_entropy < 0.2:
    level = VERY_LOW
elif overall_entropy < 0.4:
    level = LOW
elif overall_entropy < 0.6:
    level = MEDIUM
elif overall_entropy < 0.8:
    level = HIGH
else:
    level = VERY_HIGH

// 7. 自适应阈值调整
if len(history) >= 10:
    high_entropy_ratio = 近10次中HIGH/VERY_HIGH的比例
    if high_entropy_ratio > 0.5:
        所有阈值 += 0.05（放宽）
    elif high_entropy_ratio < 0.1:
        所有阈值 -= 0.05（收紧）

返回 EntropyResult
```

**算法2：自适应置信度校准算法**

```
输入：原始置信度 raw_confidence, 训练数据 (confidences, correct)
      校准方法 method（可选，默认自动选择）
输出：校准后的置信度 calibrated_confidence

// 自动选择方法
if method == AUTO:
    if len(training_data) < min_samples:
        method = TEMPERATURE
    else:
        variance = 计算置信度方差
        if variance < 0.01:
            method = TEMPERATURE
        else:
            method = HISTOGRAM

// 执行校准
if method == TEMPERATURE:
    logits = ln(raw_confidence / (1 - raw_confidence))
    scaled = logits / temperature  // temperature从训练优化得到
    calibrated = 1 / (1 + exp(-scaled))

elif method == PLATT:
    logits = ln(raw_confidence / (1 - raw_confidence))
    scaled = a × logits + b  // a, b从训练优化得到
    calibrated = 1 / (1 + exp(-scaled))

elif method == BETA:
    calibrated = β_a × confidence + (1 - β_b) × confidence²

elif method == HISTOGRAM:
    bin_idx = min(int(confidence × num_bins), num_bins - 1)
    calibrated = bin[bin_idx]的校准值

// 裁剪到[0, 1]范围
calibrated = max(0.0, min(1.0, calibrated))

// 在线更新
update(raw_confidence, is_correct):
    training_data.append((raw_confidence, is_correct))
    if len(training_data) > 1000:
        training_data = training_data[-1000:]
    if len(training_data) % 50 == 0:
        retrain(training_data)

返回 calibrated
```

## 六、有益效果

与现有技术相比，本发明具有以下有益效果：

**1. 多维度全面评估**

从一致性、格式、内容、语义四个维度对AI输出进行全面评估，克服了传统单一维度评估的片面性。每个维度都能独立检测出不同类型的质量问题，四维综合评估的覆盖面远超单一评分方法。

**2. 检测精度高**

通过四级分项熵值的加权融合计算，实现了对AI输出质量的精细化量化。加权系数根据各维度的重要性进行分配（一致性0.3、内容0.3、格式0.2、语义0.2），使评估结果更加符合实际业务需求。五级分类（VERY_LOW到VERY_HIGH）确保了对不同程度不确定性的精准识别。

**3. 自适应阈值调整**

基于历史检测结果动态调整检测阈值，避免固定阈值在不同数据分布下的过严格或过宽松问题。阈值自适应机制使系统能够在运行过程中自动优化检测灵敏度，无需人工干预。

**4. 置信度校准准确**

支持温度缩放、Platt缩放、Beta校准、直方图校准四种校准方法，覆盖了从简单到复杂的多种校准需求。自动方法选择机制确保在面对不同数据特征时始终使用最优校准方法。经校准后的置信度能够更准确地反映AI输出的真实可靠性。

**5. 系统性不确定性处理**

基于不确定性级别的分级处理策略，实现了从"自动接受"→"自动重试"→"智能干预"→"人工审核"→"安全降级"的完整策略链。避免了简单"一刀切"的重试策略在低不确定性场景下造成的不必要延迟和在高不确定性场景下的处理不足。

**6. 可扩展的策略注册机制**

通过 `register_strategy` 方法支持自定义处理策略的注册，用户可以根据业务场景扩展新的处理策略，无需修改核心逻辑。

**7. 在线学习能力**

置信度校准器支持在线增量更新，每次预测后通过 `update` 方法加入新的样本，每50个样本自动重新训练，使校准效果随运行时间持续优化。

## 八、具体实施方式

### 实施例1：AI输出质量的熵检测与校准

#### 8.1.1 场景描述

系统接收到一次AI模型生成的资费备案表单推荐结果，需要评估输出质量并校准置信度。AI输出内容如下：

```json
{
  "bossid": "P000111",
  "reporter": "BJ1",
  "action_type": "A",
  "type1": "1",
  "fees": "TODO",
  "name": "畅享套餐XXX",
  "online_day": "20260529"
}
```

#### 8.1.2 四维熵检测执行过程

**一致性熵检测：**
- 该次调用仅一次输出，无法计算一致性 → 一致性熵 = 0.0

**格式熵检测：**
- 期望格式：JSON
- 以 `{` 开头 ✓
- 尝试 `json.loads` 解析 → 成功 ✓
- 包含 `:` 和 `,` ✓
- 格式熵 = 0.0（格式规范）

**内容熵检测：**
- 必需字段列表：["bossid", "reporter", "action_type", "type1", "fees", "name"]
- 文本长度 > 10 ✓
- 检测到占位符："TODO"（在fees字段中）+0.2
- 检测到占位符："XXX"（在name字段中）+0.2
- 必需字段全部存在、没有缺失 ✓
- 内容熵总 = 0.2 + 0.2 = 0.4

**语义熵检测：**
- 期望主题："资费备案"
- 主题相似度：计算"资费备案"与输出文本的词语重叠度 → 0.5（高于0.3阈值）✓
- 禁止词检测：无不适合的词汇 ✓
- 自相矛盾检测：无矛盾对 ✓
- 重复检测：3-gram重复率 = 0.1（低于0.3）✓
- 语义熵 ≈ 0.0

**总体熵计算：**
```
总体熵 = 0.0×0.3 + 0.0×0.2 + 0.4×0.3 + 0.0×0.2 = 0.12
```

**熵级别：** VERY_LOW（总体熵0.12 < 0.2）

**检测结论：** 输出格式规范、语义合理，但内容存在未填充的占位符"TODO"和"XXX"。熵级别较低，可直接接受，但触发警告提示用户补充占位符内容。

#### 8.1.3 置信度校准

原始置信度：0.92（模型过度自信，未考虑占位符问题）

校准器使用温度缩放方法，当前温度参数为1.5（从历史训练数据优化得到）：
```
logits = ln(0.92 / 0.08) = 2.442
scaled_logits = 2.442 / 1.5 = 1.628
calibrated = 1 / (1 + e^(-1.628)) = 0.836
```

校准后置信度：0.836

**校准效果：** 原始置信度0.92被降低到0.836，更加准确地反映了输出中存在的占位符问题。

#### 8.1.4 不确定性处理

校准后置信度0.836，属于LOW级别（0.7-0.9），直接接受结果，同时标记警告信息提醒用户注意占位符。

### 实施例2：高不确定性场景的降级处理

#### 8.2.1 场景描述

AI模型在处理一个复杂查询时，输出了一个语义混乱的结果，包含禁止词和自相矛盾的内容：

```json
{"result": "该套餐没有费用限制但有费用限制，没有额外的收费可以收费"}
```

#### 8.2.2 检测与处理过程

**四维熵检测：**
- 一致性熵：多次输出差异大 → 0.7
- 格式熵：格式基本规范 → 0.0
- 内容熵：包含占位符 → 0.2
- 语义熵：自相矛盾（"没有"与"有"同时出现，"没有收费"与"可以收费"矛盾）+ 重复度高 → 0.8

**总体熵 = 0.7×0.3 + 0.0×0.2 + 0.2×0.3 + 0.8×0.2 = 0.21 + 0.06 + 0.16 = 0.43**

熵级别：MEDIUM

**置信度校准：**
- 原始置信度：0.75
- 校准后置信度：0.62（温度缩放，temperature=1.3）

**不确定性处理：**
校准后置信度0.62，属于MEDIUM级别，触发重试策略。
- 重试第1次：结果仍然包含矛盾 → 重试
- 重试第2次：结果质量提升 → 接受
- 重试后置信度提升至0.78，达到LOW级别

如果重试后仍未解决，将依次触发多样性采样、外部查询、人工审核，最终使用降级处理输出安全保守的结果。
