# 工作流编辑器布局切换锚点同步修复说明

## 问题描述

在工作流编辑器中切换水平/垂直布局时,节点的锚点(Handle)位置没有同步调整,导致:
- 垂直布局下,输入锚点应该在左侧,输出锚点应该在右侧
- 水平布局下,输入锚点应该在顶部,输出锚点应该在底部
- 但切换后锚点位置保持不变,与布局方向不匹配

## 根本原因

1. **Vue Flow 的 Handle 组件缓存机制**: Vue Flow 内部可能缓存了 Handle 的位置信息,不会自动响应 `data.anchorMode` 的变化
2. **响应式更新不足**: 虽然代码更新了 `node.data.anchorMode`,但 Vue Flow 认为节点 identity(通过 id 标识)未改变,因此不会重新创建节点组件实例
3. **缺少强制刷新机制**: 简单的数组展开操作 `[...elements.value]` 不足以触发深度重新渲染

## 解决方案

采用**清空-重建策略**强制 Vue Flow 完全重新渲染:

```javascript
const toggleAnchorMode = () => {
  const newMode = currentAnchorMode.value === 'vertical' ? 'horizontal' : 'vertical';
  const newDirection = newMode === 'vertical' ? 'LR' : 'TB';
  
  // 1. 更新全局状态
  currentAnchorMode.value = newMode;
  vueFlowDirection.value = newDirection;

  // 2. 更新所有节点的 anchorMode 和位置
  const nodes = elements.value.filter(el => !el.source && !el.target);
  nodes.forEach(node => {
    // 交换 x/y 坐标实现布局旋转
    const newX = node.position.y - minY + MARGIN;
    const newY = node.position.x - minX + MARGIN;
    node.position.x = newX;
    node.position.y = newY;
    
    // 更新 anchorMode 并添加时间戳强制刷新
    node.data = { 
      ...node.data, 
      anchorMode: newMode,
      _layoutTimestamp: Date.now()
    };
  });

  // 3. 清空再重建 elements 数组,强制完全重新渲染
  const oldElements = [...elements.value];
  elements.value = [];
  
  setTimeout(() => {
    elements.value = oldElements;
    hasChanges.value = true;
  }, 10);
};
```

## 技术要点

### 1. useNodeAnchorMode 钩子

所有节点组件使用 `useNodeAnchorMode` 钩子监听 `props.data.anchorMode`:

```javascript
// useHandlePosition.js
export function useNodeAnchorMode(props) {
  const anchorModeValue = ref(
    props.data?.anchorMode || ANCHOR_MODE_VERTICAL
  );

  // 监听 props.data.anchorMode 的变化
  watch(
    () => props.data?.anchorMode,
    (newVal) => {
      anchorModeValue.value = newVal || ANCHOR_MODE_VERTICAL;
    },
    { immediate: true }
  );

  const anchorMode = computed(() => anchorModeValue.value);
  const { targetPosition, sourcePosition } = useHandlePosition(anchorMode);

  return { targetPosition, sourcePosition, isVertical };
}
```

### 2. 节点组件使用示例

```vue
<!-- StartNode.vue -->
<script setup>
import { useNodeAnchorMode } from './useHandlePosition.js';

const props = defineProps({
  data: { type: Object, required: true },
  // ... 其他 props
});

const { sourcePosition } = useNodeAnchorMode(props);
</script>

<template>
  <div class="node start-node">
    <!-- 节点内容 -->
    <Handle type="source" :position="sourcePosition" id="source" />
  </div>
</template>
```

### 3. 清空-重建策略的优势

- **彻底清除缓存**: 清空 `elements.value` 会销毁所有节点组件实例
- **强制重新创建**: 重新赋值会创建全新的组件实例,读取最新的 `anchorMode`
- **避免复杂的状态管理**: 不需要在每个节点中添加额外的刷新逻辑

## 测试步骤

1. 打开工作流编辑器
2. 创建几个节点并连接
3. 点击工具栏的布局切换按钮(垂直↔水平)
4. 观察锚点位置是否正确调整:
   - ✅ 垂直布局: 输入在左,输出在右
   - ✅ 水平布局: 输入在上,输出在下
5. 尝试拖拽连线,确认连接功能正常

## 注意事项

1. **性能影响**: 清空-重建会导致短暂的闪烁(约10ms),但对用户体验影响极小
2. **边的处理**: 边(edges)会自动跟随节点重新渲染,无需特殊处理
3. **选中状态**: 切换布局后会丢失选中状态,这是预期行为
4. **撤销/重做**: 布局切换会被记录到历史中,可以撤销

## 后续优化建议

如果未来发现性能问题,可以考虑:
1. 使用 Vue 的 `key` 属性为每个节点添加基于 `anchorMode` 的动态 key
2. 实现增量更新机制,只重新渲染受影响的节点
3. 添加过渡动画使布局切换更平滑
