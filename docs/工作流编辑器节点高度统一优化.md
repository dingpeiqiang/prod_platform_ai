# 工作流编辑器节点高度统一优化

## 优化目标
统一工作流编辑器中所有节点的最小高度，使节点在画布上保持一致的视觉高度，便于布局调整和美观性提升。

## 优化内容

### 1. 统一最小高度设置
为所有节点类型添加了统一的 `min-height: 120px` 样式规则，确保所有节点具有相同的最小高度。

- **ConditionNode**: 原本设置为 180px，调整为 120px 以保持一致性

## 优化效果

### 视觉效果
1. **一致性**: 所有节点在画布上具有统一的最小高度，视觉上更加整齐
2. **对齐**: 节点之间的垂直对齐更加容易，布局调整更直观
3. **美观**: 整体工作流图表看起来更加专业和统一

### 用户体验
1. **布局调整**: 用户在拖拽和调整节点位置时，更容易保持整齐的布局
2. **视觉识别**: 统一的节点高度有助于用户快速识别和理解工作流结构
3. **操作便利**: 节点间距和对齐更加一致，减少视觉疲劳

## 技术实现

### CSS 样式修改
在每个节点组件的 `<style scoped>` 部分，为节点基础类添加：
```css
min-height: 120px; /* 统一节点最小高度 */
```

### 兼容性考虑
1. **响应式设计**: 使用 `min-height` 而非固定 `height`，允许节点根据内容自动扩展
2. **配置模式**: 配置模式下的节点不受此限制影响，可以正常显示完整内容
3. **紧凑模式**: 紧凑模式节点也遵循统一高度规范

1. 本次优化仅设置最小高度，不影响节点内容的正常显示
2. 节点仍可根据内容自动扩展高度，保持良好的用户体验
3. 所有修改均使用 scoped 样式，不会影响其他组件
4. 保持了原有的节点功能和交互行为
