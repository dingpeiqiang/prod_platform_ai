# MCP 外部工具参数配置指南

## 一、参数类型说明

外部工具支持以下参数类型：

| 类型 | 说明 | 示例 |
|------|------|------|
| **string** | 字符串类型 | 用户名、邮箱地址 |
| **integer** | 整数类型 | 数量、年龄 |
| **number** | 数字类型 | 价格、百分比 |
| **boolean** | 布尔类型 | 是否启用 |
| **object** | 对象类型 | 包含多个属性的复杂对象 |
| **array** | 数组类型 | 多个相同类型的元素 |

## 二、数组类型配置详解

### 2.1 基本数组（简单类型数组）

**场景**：参数是一个字符串数组、整数数组等。

**示例**：用户标签列表 `["admin", "vip", "active"]`

**配置方法**：

1. 在参数表格中新增一行
2. 填写参数信息：
   - **参数英文名称**：`tags`
   - **参数描述**：`用户标签列表`
   - **数据类型**：选择 `array`
   - **是否必填**：根据需要选择
   - **默认值**：`[]` 或留空

3. **重要**：点击「新增子项」按钮添加数组元素类型

4. 添加子项：
   - **参数英文名称**：留空或填写元素名称（如 `item`）
   - **参数描述**：如「标签」
   - **数据类型**：选择 `string`（或 integer、number 等）
   - **是否必填**：根据需要选择

### 2.2 对象数组（复杂类型数组）

**场景**：参数是一个对象数组，每个对象包含多个属性。

**示例**：订单列表，每个订单包含订单号、金额、状态等。

**配置方法**：

1. 在参数表格中新增一行
2. 填写参数信息：
   - **参数英文名称**：`orders`
   - **参数描述**：`订单列表`
   - **数据类型**：选择 `array`
   - **是否必填**：根据需要选择

3. **重要**：点击「新增子项」按钮添加数组元素结构

4. 添加子项：
   - **参数英文名称**：如 `order`
   - **参数描述**：如「单个订单」
   - **数据类型**：选择 `object`
   - **是否必填**：根据需要选择

5. **再次点击「新增子项」**：为对象添加属性
   - **参数英文名称**：`order_id`
   - **参数描述**：`订单号`
   - **数据类型**：选择 `string`
   - **是否必填**：勾选

   - **参数英文名称**：`amount`
   - **参数描述**：`订单金额`
   - **数据类型**：选择 `number`
   - **是否必填**：勾选

   - **参数英文名称**：`status`
   - **参数描述**：`订单状态`
   - **数据类型**：选择 `string`
   - **是否必填**：勾选

### 2.3 嵌套数组

**场景**：二维数组或更复杂的嵌套结构。

**示例**：用户分组，每个分组包含多个用户 ID。

**配置方法**：

1. 创建顶级数组参数：
   - **参数英文名称**：`user_groups`
   - **数据类型**：选择 `array`

2. 添加子项（第一层数组）：
   - **参数英文名称**：如 `group`
   - **数据类型**：选择 `array`

3. 添加子项（第二层数组）：
   - **参数英文名称**：如 `user_id`
   - **数据类型**：选择 `integer`

## 三、完整配置示例

### 示例 1：创建商品接口

**OpenAPI 规范片段**：

```yaml
requestBody:
  content:
    application/json:
      schema:
        type: object
        properties:
          name:
            type: string
            description: 商品名称
          tags:
            type: array
            items:
              type: string
            description: 商品标签
          variants:
            type: array
            items:
              type: object
              properties:
                size:
                  type: string
                color:
                  type: string
                price:
                  type: number
```

**参数配置**：

| 参数名 | 描述 | 类型 | 必填 | 子项配置 |
|--------|------|------|------|----------|
| `name` | 商品名称 | string | ✓ | - |
| `tags` | 商品标签 | array | - | string 类型的子项 |
| `variants` | 商品规格 | array | - | object 类型的子项，包含 size、color、price |

### 示例 2：批量查询接口

**场景**：根据多个 ID 批量查询商品信息。

**参数配置**：

| 参数名 | 描述 | 类型 | 必填 | 子项配置 |
|--------|------|------|------|----------|
| `ids` | 商品ID列表 | array | ✓ | integer 类型的子项 |

## 四、常见问题

### Q1: 为什么数组参数需要配置子项？

**A**：数组参数本身只定义了这是一个数组，但系统需要知道数组中元素的类型和结构。子项配置告诉系统：
- 数组元素的数据类型（string、integer、object 等）
- 如果是 object 类型，还需要知道包含哪些属性

### Q2: 数组的默认值怎么填？

**A**：
- 简单类型数组：`["value1", "value2"]` 或 `[]`
- 空数组：`[]`
- 如果不确定，可以留空

### Q3: 如何删除数组的子项？

**A**：
1. 找到要删除的子项行
2. 点击该行最后的「删除」按钮（红色垃圾桶图标）
3. 子项会连同其下的所有子子孙孙一起被删除

### Q4: 如何调整子项的顺序？

**A**：目前不支持拖拽调整顺序。如需调整，可以：
1. 记录当前配置
2. 删除所有子项
3. 按新顺序重新添加

### Q5: 数组嵌套深度有限制吗？

**A**：系统支持多层嵌套，但建议保持嵌套深度在 3 层以内：
- ✅ 推荐：`array → object → string/integer/array`
- ⚠️ 谨慎：`array → array → object → array → object`
- ❌ 不推荐：超过 3 层嵌套

## 五、配置检查清单

配置数组参数时，请确认以下内容：

- [ ] 已选择正确的数据类型（`array`）
- [ ] 已点击「新增子项」按钮
- [ ] 子项的数据类型正确（string/integer/object 等）
- [ ] 如果是 object 类型，已配置所有必要属性
- [ ] 必填属性已勾选「是否必填」
- [ ] 参数描述清晰明确
