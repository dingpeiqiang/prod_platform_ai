## 3. 闭环对照（目标 vs 现状）

```
告警/批量稽核 → 根因证据链 → 假设推演 → 工单闭环 → 真实主数据回写
     ✅              ✅            ✅          ✅        🔶契约已齐/地址未接
```

对话路径：

```
快捷入口绑定 scene → ChatStream SSE → ProductOps*Handler
  → product-ontology 引擎 → 消息卡片 + 右侧富面板
```

事实图路径：

```
BOSS/CRM ops-graph(OpsGraph-v1)
  → HttpOpsProductDataSource → OpsProductGraphLoader
本进程发布：OpsGraphPublishService → GET /api/v1/product-center/ops-graph
```
