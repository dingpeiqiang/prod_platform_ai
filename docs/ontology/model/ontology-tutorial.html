场景 ① · 上架前

配置合规：要不要让它上架

痛点：人工逐项核对易漏 · 产出：过 / 不过的明确结论 + 违规明细
1取字段值
实例OF-CFG-C06-CH 亲情宽带加固包
字段channelScope=""（空） · fixedFeeAmount=19.0
2规则判定
规则R-C06.channel：渠道范围为空 → 必填字段缺失
求值"" = 空 ✓ 命中 → 推得 C06MissingRequired
3另一条规则
实例OF-CFG-C09-HIGH 600元宽带套餐
规则R-C09.high：固费高于合规上限 → 资费越界
求值600.0 > 599.0 ✓ 命中 → C09FeeRangeViolation
4类层级归集
前提C06MissingRequired ⊑ ConfigViolationOffering
前提C09FeeRangeViolation ⊑ ConfigViolationOffering
结论两个子类都归父类 → 违规商品，退回整改

场景 ② · 上线后

告警分级：严不严重、谁该先处理

痛点：轻重缓急靠人判断 · 产出：客观等级 + 严重问题自动建单
1取指标
实例OF-ALERT-FEE-P0 计费差错告警
字段feeErrorRate=0.05 · errorCount=4.0 · orderCount=320.0
2一级规则判定
规则R-E01.fee：计费差错率高于等于一级门槛
求值0.05 ≥ 0.05 ✓ 命中 → P0AlertOffering
3未升级检查
规则R-E01.err：异常量 ≥ 10 才一级
求值4.0 ≥ 10 不成立 → 不影响 P0 结论（费率已命中）
4类层级 + 强制建单
前提P0AlertOffering ⊑ AlertOffering
规则R-E04.p0：一级告警强制建单
结论→ NeedWorkOrderOffering，自动建单 · 30 分钟时限

场景 ③ · 运营中

指标异动归因：为什么掉了

痛点：逐条排查耗半天 · 产出：带证据的 Top3 候选根因
1判异动（点火）
实例99898653 家庭融合畅享128 · hasMetric v-M-1
字段metricDelta=−0.18 · anomalyFlag=true
规则R-A01.delta：环比低于等于异动阈值 −0.10
求值−0.18 ≤ −0.10 ✓ 命中 → AnomalyOffering
2渠道证据
对象soldOn CH-HALL 营业厅
规则R-A02：订单跌幅≤−0.20 且贡献占比≥0.30
求值−0.20 / 0.30 双达标 ✓ 主因候选 · weight 0.30
3促销证据
对象participatesIn PR-HF-GIFT 融合加装礼
规则R-A03：临期天数≤7 且驱动单占比≥0.25
求值5 天 / 0.31 ✓ 主因候选 · weight 0.31
4竞品证据
对象competesWith CP-F120 竞品融合120
规则R-A04：价差比例≥0.15 且渗透率有升
求值0.156 / +2.1pp ✓ 主因候选 · weight 0.18
5行为证据
对象influencedBy UB-RENEW 续约率下降
求值weightHint 0.09，低于前三 → 不入选
6按权重取 Top3
排序0.31（促销） > 0.30（渠道） > 0.18（竞品）
结论① 促销到期 ② 营业厅渠道 ③ 竞品分流 → 候选根因

场景 ④ · 定期

风险稽核：存量里哪些该清理

痛点：定期盘点易漏 · 产出：风险清单 + 高/中/低分级整改
1取字段值
实例84176765 校园流量包（0元）
字段monthlyFee=0.0 · oneTimeFee=0.0 · inWhitelist=false
字段onShelf=true · hasContract=false
2第一跳 · 零元资费风险
规则R-B01.zeroFee：月费为0 且 一次性费用为0 且 不在白名单
求值0.0=0.0 ∧ 0.0=0.0 ∧ false=false ✓ 命中
结论→ ZeroFeeRiskOffering ⊑ HighRiskOffering
3第二跳 · 在架无合约
规则R-B02：已判零元资费风险，且在架 且 无合约
前提上一步已成立 ZeroFeeRiskOffering
求值onShelf=true ∧ hasContract=false ✓ 命中
结论→ ZeroFeeNoContractOffering
4分级输出
前提ZeroFeeNoContractOffering ⊑ ZeroFeeRiskOffering ⊑ HighRiskOffering
结论两跳叠加仍属高风险品 → 高 · 立即整改，进风险清单

场景 ⑤ · 运营中

优化建议：接下来该做什么

痛点：知道问题不知下一步 · 产出：可直接执行的具体建议
1取下降旗标
实例OF-SUG-O01 · 收入环比 −0.12（阈值 −0.10）
字段revenueDropFlag=true · churnUsersRiseFlag=false
其他attachRate / arpu / activeUsers 旗标均为 false
2规则映射建议

求值true ✓ 命中 → ChannelPromotionOffering
其余R-O02~R-O05 前件为 false → 均不触发
3类层级归集
前提ChannelPromotionOffering ⊑ SuggestionOffering
规则R-O00.cp：渠道促销建议商品 → 运营建议商品
结论→ 运营建议商品，输出 一条可执行动作：渠道促销
