# 自定义模型配置功能说明

## 功能概述

优化后的模型配置功能支持自定义 Provider 的完整配置和测试，包括基础配置和高级参数设置。

## 主要改进

### 1. 前端界面优化

#### Provider 类型选择
- **自定义 (OpenAI 兼容)**: 支持任何 OpenAI 兼容的 API
- **OpenAI**: 预设 OpenAI 官方 API
- **MiniMax**: 预设 MiniMax API

#### 基础配置项
- **模型名称**: 例如 `gpt-4`, `qwen-plus`, `claude-3`
- **API Key**: 支持显示/隐藏切换
- **Base URL**: OpenAI 兼容 API 的基础 URL

#### 高级配置（可折叠）
- **Temperature** (0-2): 控制输出的随机性
  - 0: 确定性输出
  - 0.3: 默认值，平衡创造性和准确性
  - 0.8-1.0: 更具创造性
  - 2.0: 最大随机性
  
- **Max Tokens** (1-32768): 最大输出 token 数
  - 512: 短回复
  - 2048: 默认值，适合大多数场景
  - 4096+: 长文本生成
  
- **Thinking Mode**: 启用思考模式
  - 显示模型的推理过程（如果模型支持）
  - 适用于需要理解模型决策过程的场景

### 2. 后端增强

#### 详细的日志记录
所有模型调用都会记录详细日志：
```
[INFO] [OpenAIProvider] 开始同步调用 - URL: https://..., Model: qwen-plus
[ERROR] [OpenAIProvider] 请求失败 - HTTP 401: Incorrect API key
```

#### 智能错误处理
- 配置完整性检查
- HTTP 错误码解析
- 网络异常分类
- 友好的错误提示

#### 响应预览
测试成功时返回响应预览（前100字符），帮助用户确认模型工作正常。

### 3. 配置持久化

- **自动保存**: 点击"测试连接"时自动保存配置到 localStorage
- **自动加载**: 页面刷新后自动恢复上次配置
- **安全考虑**: API Key 保存在本地，不会发送到服务器存储

## 使用指南

### 基本配置流程

1. **选择 Provider 类型**
   - 对于阿里云 DashScope、百度文心一言等，选择"自定义 (OpenAI 兼容)"
   - 对于 OpenAI 官方 API，选择"OpenAI"

2. **填写基础信息**
   ```
   模型名称: qwen-plus
   API Key: sk-xxxxxxxxxxxxx
   Base URL: https://dashscope.aliyuncs.com/compatible-mode/v1
   ```

3. **测试连接**
   - 点击"测试连接"按钮
   - 查看测试结果和响应预览
   - 如有错误，查看详细错误信息

4. **应用配置**
   - 测试成功后点击"应用配置"
   - 配置立即生效

### 高级配置调优建议

#### Temperature 调整
- **代码生成**: 0.1-0.3 (需要准确性)
- **创意写作**: 0.7-1.0 (需要多样性)
- **数据分析**: 0.0-0.2 (需要确定性)
- **日常对话**: 0.3-0.5 (平衡)

#### Max Tokens 设置
- **简单问答**: 256-512
- **普通对话**: 1024-2048
- **长文生成**: 4096-8192
- **超长文本**: 16384+

#### Thinking Mode
- **开启**: 调试、学习、理解模型推理
- **关闭**: 生产环境、节省 token、提高速度

## 故障排查

### 常见问题

#### 1. "配置不完整" 错误
**原因**: API Key 或 Base URL 为空  
**解决**: 确保填写了所有必填字段

#### 2. "HTTP 401" 错误
**原因**: API Key 无效或已过期  
**解决**: 
- 检查 API Key 是否正确
- 确认账户余额充足
- 重新生成 API Key

#### 3. "HTTP 403" 错误
**原因**: 权限不足  
**解决**: 
- 确认 API Key 有访问该模型的权限
- 检查账户是否被限制

#### 4. "HTTP 404" 错误
**原因**: 模型不存在或路径错误  
**解决**: 
- 检查模型名称拼写
- 确认 Base URL 正确
- 查阅 API 文档确认模型可用性

#### 5. "连接超时" 错误
**原因**: 网络问题或服务器响应慢  
**解决**: 
- 检查网络连接
- 尝试更换网络
- 稍后重试

#### 6. "SSL 证书错误"
**原因**: HTTPS 证书问题  
**解决**: 
- 检查系统时间是否正确
- 更新根证书
- 联系 API 提供商

## API 接口说明

### 测试模型配置

**端点**: `POST /api/v1/chat/model/test`

**请求体**:
```json
{
  "provider": "custom",
  "model": "qwen-plus",
  "apiKey": "sk-...",
  "baseUrl": "https://...",
  "temperature": 0.3,
  "maxTokens": 2048,
  "thinking": false
}
```

**成功响应**:
```json
{
  "success": true,
  "message": "模型连接测试成功",
  "provider": "custom",
  "model": "qwen-plus",
  "response_preview": "你好！我是通义千问..."
}
```

**失败响应**:
```json
{
  "success": false,
  "message": "认证失败: API Key 无效或已过期",
  "detail": "HTTP 401: Incorrect API key provided..."
}
```
