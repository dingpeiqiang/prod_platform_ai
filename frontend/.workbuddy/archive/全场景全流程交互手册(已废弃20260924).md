# 产商品研发助手 · 全场景交互手册

> 覆盖 **工作台 + 3 个助手 + 9 个对话场景**。
> 每个场景只讲三件事：**怎么进 → 你说什么 → 系统给什么**。

---

## 一、工作台（驾驶舱）

**工作台是总入口**，本身不处理业务，负责调度三个助手：

- **进入方式一**：顶部随时点「工作台 / 研发 / 运营 / 查询」切换，当前对话自动存入历史；
- **进入方式二**：首页点击助手卡片直接进入；
- 也可以不选助手直接提问，对话会归入「自由对话」历史分组。

页面为三栏：左侧是场景入口和历史对话，中间是对话区，右侧是随场景自动出现的面板（配置工作台、运营看板、商品档案、比对结果等）。

**驾驶舱的调度能力：** 助手之间会互相配合。例如运营助手给出优化方案后，会自动调用查询助手核实商品情况、调用研发助手生成配置工作台；在工单中心点某个商品的运营指标，会自动跳到运营助手打开看板。

## 二、产品研发助手

管**产品上线前**的事：做活动、配资费、定规则。

### 场景 1：营销活动管理

- **怎么进**：选中研发助手后，点左侧「营销活动管理」。
- **你说**：`为"智享99元5G套餐"策划并落地一个开学季拉新活动`
- **系统给**：活动策划与落地支持（当前为演示回复，接入真实模型后输出活动方案）。

### 场景 2：资费配置 ★核心场景

- **怎么进**：点左侧「资费配置」，输入框上方出现三种配置方式，任选其一。

**方式一：对话式配置** —— 说一句话就出配置单

1. 你说：`配个套餐，月租99元，流量500M，语音1000分钟`
2. 系统解析出字段清单，**右侧自动打开配置工作台**：你提到的字段标「已解析」，AI 补全的标「AI推荐」（悬停可看理由），沿用惯例的标「复用」；
3. 可以继续用对话改：`商品叫青春卡39` / `月费改成59元` → 工作台字段实时更新；
4. 点「智能稽核」做提交前校验 → 点「提交配置」→ 生成工单号进入审批；
5. 工作台收起后，输入框上方留有还原条，随时一键恢复。

**方式二：文件导入批量配置** —— 传一个文件，配一批套餐

1. 选中该方式，上传配置文件（支持拖拽、粘贴）；
2. 系统解析出多个商品（如 3 档校园卡套餐），写入右上角「我的草稿」，并自动打开第一个的工作台；
3. 逐个完善提交，提交一个自动跳下一个，也可用「上一个 / 下一个」切换。

📷 批量解析结果表｜📷 我的草稿抽屉

**方式三：存量商品复制配置** —— 找一个老套餐当模板

1. 选中该方式，按商品编码或名称检索存量商品；
2. 点「查看详情」打开只读档案，点「复制」即生成可编辑的新商品，走与方式一相同的提交流程。

📷 存量检索结果｜📷 只读档案（含复制按钮）

### 场景 3：业务规则管理

- **怎么进**：点左侧「业务规则管理」。
- **你说**：`为"智享99元5G套餐"配置受理与鉴权规则` / `配置短信与验证码规则，并检查是否冲突`
- **系统给**：受理、鉴权、短信、验证码、无纸化、入网等规则的统一配置与冲突检查（当前为演示回复）。

## 三、产品运营助手

管**产品上线后**的事：看数据、查异动、出方案。

**特别入口**：欢迎页有「产品运营视图」卡片，点击在右侧打开运营看板（收入总览、重点产品、异动预警）。

📷 产品运营视图看板

### 场景 1：运营数据分析

- **你说**：`帮我看下本周活跃用户的涨跌原因`
- **系统给**：关键指标表（活跃/新增/收入 + 环比）→ 归因结论 → 建议动作；提到具体产品（如家庭宽带）时给出该产品的专属解读。
- 附按钮：「打开运营视图」「下钻家庭宽带」等。

📷 趋势解读回复（指标表 + 归因）

### 场景 2：异动归因分析

- **你说**：`帮我分析一下畅享59元套餐的新增异动`
- **系统给**：异动概览（健康评分 72 分、新增降 25.3%）→ 四条核心发现 → 根因贡献度表（流量落后竞品占 50%）；
- 回复带「查看完整版报告」入口，右侧展开图表化根因分析（产品画像、趋势图、竞品对标）。

📷 异动归因摘要｜📷 完整版根因分析报告

### 场景 3：优化方案咨询

- **你说**：`针对上面的分析结果，给出具体的优化方案`
- **系统给**：方案A（新商品策划，流量 30→40GB，预计月净增收益 +28~33 万，推荐）与方案B（产品下线，不推荐），请你拍板。

**确认「启动产品优化」后，完整链路自动推进：**

> 调用查询助手核数据 → 调用研发助手打开预填好的配置工作台 → 智能稽核 → 提交审批 → 审批通过（AI 主动播报）→ 测试报告到达（AI 主动播报）→ 发起备案公示 → 选择销售渠道 → 上架销售 → 归档到工单中心

顶部流程条全程同步：**方案设计 → 商品配置 → 预览审批 → 测试审核 → 备案公示 → 上架销售**。

📷 执行摘要 + 预填工作台｜📷 备案公示页签｜📷 销售渠道页签

## 四、产品查询助手

管**找资料**的事：问商品、调档案、做比对。

### 场景 1：智能问答

- **问商品**：`智享99元5G套餐包含多少流量？` → 要点速览卡（月费/流量/语音/状态）+「调阅配置档案」按钮。
- **问制度**：`备案公示的时限是怎么规定的？` → 引用具体规范条文作答，并标注出处（如《资费商品备案公示管理规范（2026版）》）。
- **会记上下文**：问完智享99后直接说「调阅该商品的档案」，"该商品"自动指上一轮聊过的套餐。

📷 商品问答速览卡｜📷 制度问答（带引用来源）

### 场景 2：档案调阅

- **你说**：`调阅"动感地带59元套餐"的配置档案` 或 `查一下 SP2024082002 的档案`
- **系统给**：右侧打开只读档案工作台，五个页签：基础信息 / 资源配置 / 测试报告 / 备案公示 / 销售渠道。
- **跨助手联动**：说「查一下我最近配置的套餐」，可以调出你在研发助手配置的草稿档案。

📷 档案工作台（五页签）｜📷 测试报告页签

### 场景 3：比对分析

- **你说**：`对比畅享59元套餐和智享99元5G套餐`
- **系统给**：右侧打开比对面板——资费要素对比表（优势项高亮）、资源量柱状图、差异结论。
- **可以继续改**：`把智享99换成动感地带59` / `叠加畅享校园卡39` / `去掉畅享59`，面板实时刷新。

## 五、全局功能

右上角常驻四个入口：

| 入口 | 用途 |
|---|---|
| 📄 我的草稿 | 未提交的套餐草稿，点击继续配置 |
| 📋 我的商品 | 已提交和已上架的商品统一管理，支持搜索，可回看档案、跳转运营指标 |
| 🔔 消息通知 | 我的审批 + 今日待办（异动/合约/合规三级，可直接点「分析」「续约处理」「补录」触发 AI 处理） |
| 👤 用户菜单 | 当前登录用户 |

其他通用能力：新建会话、历史对话全文检索（支持按工单号搜）、删除会话、文件/图片/语音输入、模型切换。

📷 通知下拉（审批 + 待办）｜📷 审批进度抽屉｜📷 工单中心
