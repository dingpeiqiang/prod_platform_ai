## 一、产品概述

### 1.1 产品定位

**AI 原生产品工作台**是由「一个工作台 + 三个 AI 助手」构成的**产品全生命周期作业平台**。它将资费产品从配置、审批、上架，到运营监控、问题分析、优化迭代的全过程，收敛到同一个工作台中完成——**用户用自然语言表达诉求，AI 完成解析、编排与执行**。

### 1.2 解决的问题

资费产品的全流程过去普遍存在两个问题：

1. **环节断层**——配置、审批、运营分处不同系统，数据不互通，产品"上线前如何配置"与"上线后表现如何"难以对应。
2. **操作繁重**——配置一款产品需要填写大量表单字段；获取分析结论需要另行提报数据需求；查询历史配置需要跨目录检索。

工作台通过"三个助手协同 + 一份产品数据"的方式打通上述环节，让配置、审批、运营与查询在同一个界面内衔接完成。

### 1.3 产品全流程

```text
产品创意 → 立项设计 → 资费配置 → 提交审批 → 审批通过（即上架） → 运营监控 → 发现问题 → 优化迭代 → （回到配置）
```

其中：**上线前**的工作由产品研发助手承担，**上线后**的工作由产品运营助手承担，**资料查询**由产品查询助手全程支持。

## 二、总体架构与交互范式

### 2.1 一个工作台（驾驶舱）

工作台是所有操作的统一入口，采用**三栏式布局**：

| 区域 | 内容 | 说明 |
|---|---|---|
| **左栏** | 快捷场景 + 历史对话 | 当前助手可用的场景入口；历史对话支持检索与删除；顶部提供「新建会话」 |
| **中栏** | 对话区 | 与 AI 对话的主区域；输入框上方会按场景动态出现配置方式、快捷动作等 |
| **右栏** | 动态面板 | 随场景自动出现的作业面板：配置工作台、产品档案、比对面板、运营看板等 |

**顶部导航**用于在三个助手之间切换：

```text
工作台 ｜ 产品研发助手  产品运营助手  产品查询助手          我的草稿  我的产品  消息通知  用户菜单
```

切换助手时，当前对话会自动归档到历史对话中，可随时切回继续。

### 2.2 三位助手的分工与关系

| 助手 | 职责 | 覆盖环节 | 主要场景 |
|---|---|---|---|
| 🧪 **产品研发助手** | 把产品**做出来** | 产品**上线前** | 资费配置 |
| 📈 **产品运营助手** | 把产品**运营好** | 产品**上线后** | 运营数据分析 · 异动归因分析 · 套餐优化建议 |
| 🔍 **产品查询助手** | 让资料**查得到** | **贯穿全程** | 智能问答（含档案调阅） · 比对分析 |

三者并非相互独立的工具，而是同一工作台中的三个角色：

```mermaid
flowchart LR
  A["产品研发助手<br/>上线前：配资费"] -->|产品上架| B["产品运营助手<br/>上线后：看数据 / 查异动 / 出方案"]
  B -.->|"发现异动，需要优化"| A
  C["产品查询助手<br/>贯穿全程：问商品 / 调档案 / 做比对"]
  C -.-> A
  C -.-> B
```

- **研发 → 运营**：研发助手配置上架的产品，进入运营助手的监控范围；从工单中心点击某产品的"运营指标"，会直接跳转到运营助手并打开其看板。
- **运营 → 研发**：运营助手在给出优化方案后，可一键"启动产品优化"，**自动调用研发助手**打开一份预填好的配置工作台，使"发现问题"直接衔接"解决问题"。
- **查询贯穿全程**：研发阶段可检索存量产品作为配置模板，运营阶段可核实产品资费画像；且研发助手配置的草稿，查询助手同样可以调阅与比对。

**三个助手面对的是同一个产品、同一份数据**——研发助手配置的资费要素、运营助手看到的用量指标、查询助手调出的产品档案，指向同一个产品对象。

### 2.3 四种核心交互方式

| 交互方式 | 说明 | 典型体现 |
|---|---|---|
| **对话式** | 用自然语言表达诉求，AI 解析并执行 | "配置一档……数据卡"即生成配置单 |
| **面板联动** | 对话与右侧面板实时联动 | 说到配置，右侧自动打开配置工作台 |
| **跨助手接力** | 一个助手可自动调用其他助手 | 运营"启动产品优化"→ 自动调用查询、研发助手 |
| **多模态输入** | 文件、图片、语音均可作为输入 | 上传需求表批量解析、按住说话 |

### 2.4 两个全局设定

**① 运营身份（按工号区分数据范围）**

运营助手面向两类使用角色：

- **平台运营**（联通国际视角）：管理**代理商 / 地区 / 套餐**；
- **代理商运营**（一级总代视角）：管理**个人用户 / 套餐 / 用量**。

**运营助手的视角由登录工号自动决定**：平台方工号进入后看到全局数据，代理商工号进入后看到其自营数据，**不同工号的数据范围相互隔离**，无需人工选择。视角不同，看板的数据范围与口径、对话场景、欢迎页能力标签也随之不同，便于平台方与代理商在**同一系统中各取所需、彼此对账**。

> 说明：演示环境使用单一账号，因此界面提供了「运营视角」切换入口，用于在同一账号下演示两种身份的差异；正式环境将随工号自动匹配。

**② 字段来源标签**

配置工作台中的字段带有来源标签，用于标识该字段的取值依据：

| 标签 | 含义 |
|---|---|
| **已解析** | 由用户需求直接解析得出的字段（悬停显示"根据用户需求解析得出"） |
| **AI 推荐** | 由 AI 依据业务模板（并参考产品库中相似产品）自动补全的字段（悬停显示补全理由） |

> 产品档案的只读调阅属于历史归档数据，不显示上述标签。

## 三、产品研发助手 · 全流程交互

### 3.1 场景进入

在顶部导航选择「产品研发助手」，左栏即出现快捷场景。研发助手当前提供**资费配置**场景，用于完成资费产品的配置与提交。

进入「资费配置」后，**输入框上方出现"选择配置方式"，提供三种配置方式**，分别对应不同的配置情形：

| 配置方式 | 适用情形 |
|---|---|
| **对话式配置** | 配置单款产品，直接用自然语言描述需求 |
| **文件导入批量配置** | 一次配置多款产品，已有需求清单/配置表 |
| **存量产品复制配置** | 新产品与某款存量产品接近，以其为模板复制修改 |

### 3.2 交互方式一：对话式配置

**第 1 步 · 描述需求。** 在输入框中用一句话描述产品与资费要素，例如：

> 配置一档 WeWalk-Data Only-香港.台湾共用 30 日不限量（30GB 高速）数据卡：一次性资费，高速配额 30GB，有效期 30 天，漫游地香港.台湾，PCRF 限速。

**第 2 步 · 查看解析结果。** 系统将自然语言解析为结构化字段，返回「**对话式配置 · 字段解析结果**」表格，列出已识别字段及其取值；同时完成以下动作：

- 自动生成**工单编号**；
- 登记至右上角「**我的草稿**」；
- **在右侧自动打开「配置工作台」**。

**第 3 步 · 确认字段来源。** 工作台中，用户明确提及的字段标记为 **已解析**，AI 补全的字段标记为 **AI 推荐**，可悬停查看补全理由。

**第 4 步 · 对话式修改。** 如需调整，可直接继续对话，例如"月费改为 198 元""漫游地增加澳门"，工作台字段将实时更新。

**第 5 步 · 稽核与提交。** 点击「**智能稽核**」进行提交前校验，通过后点击「**提交配置**」，产品进入审批。

> 附加包（加油包）同样支持对话式配置，系统会自动切换至附加包模板，并提示"归属产品、语音/短信资源量待确认"等信息。

### 3.3 交互方式二：文件导入批量配置

适用于一次配置多款产品的场景。

1. 选择「文件导入批量配置」，**上传配置文件**（支持拖拽与粘贴）；
2. 系统解析出多款产品，返回「**文件导入批量配置 · 解析结果**」目录表（含产品名称、工单编号、资费概要、状态），并写入「我的草稿」，同时**自动打开第一款产品的工作台**；
3. 依次完善并提交，**提交一款后自动跳转至下一款**；工作台底部提供"上一个 / 第 x 个 · 共 y 个 / 下一个"导航；全部提交后，提示"全部草稿产品已提交，进入审批阶段"。

### 3.4 交互方式三：存量产品复制配置

适用于新产品与存量产品接近的情形。

1. 选择「存量产品复制配置」，**输入框切换为"槽位模板"**，按模板填写检索条件：

   > 我想要查【套餐类型：预付费主套餐 / 附加包】的【套餐名称】套餐，套餐编码为【套餐编码】。

2. 系统按名称或编码检索**存量产品库**，返回「**存量产品复制配置 · 检索结果**」表格；
3. 点击「查看详情」打开该产品的**只读配置档案**；确认无误后点击「**复制**」，即可**生成一张可编辑的新产品**（产品名称自动追加"（复制）"、生成新工单编号），后续流程与对话式配置一致。

**存量产品库（示例，共 5 档）**

| 产品编码 | 产品名称 | 业务模板 |
|---|---|---|
| `SP-HK-TW-1D` | WeWalk-Data Only-澳门.香港.台湾共用1日不限量(800MB/日高速) | 可选包·数据卡 |
| `SP-HK-TW-3D` | WeWalk-Data Only-澳门.香港.台湾共用3日不限量(800MB/日高速) | 个人主资费·数据卡 |
| `SP-HK-TW-15D` | WeWalk-Data Only-澳门.香港.台湾共用15日不限量(15GB高速) | 个人主资费·数据卡 |
| `SP-HK-TW-30D` | WeWalk-Data Only-澳门.香港.台湾共用30日不限量(30GB高速) | 个人主资费·数据卡 |
| `SP-HK-TW-30D-HIGH` | WeWalk-Data Only-澳门.香港.台湾共用30日不限量(3GB/日高速) | 个人主资费·数据卡 |

### 3.5 配置工作台

三种配置方式最终都收口于同一张**配置工作台**，共四个页签：

| 页签 | 主要内容 |
|---|---|
| **基础信息** | 产品类型、卡类型、网络类型、开户/漫游模版、产品编码、名称、描述、发布租户、退订规则、订购附加产品、归属产品等 |
| **属性信息** | 资费类型、有效期属性、资源重置周期、产品有效期、是否激活、延长生命周期、重复订购、唤醒激活、延长期限等 |
| **资源配置** | 数据资源（高速配额、漫游地、限速策略、限速模版）、语音资源、短信资源 |
| **信息预览** | 按配置内容渲染的 APP 展示预览（用户 / 免填单 / 短信三视图） |

工作台底部提供三个操作：**保存草稿 / 智能稽核 / 提交配置**。

### 3.6 智能稽核与提交审批

**智能稽核**在提交前依次执行四类校验，并给出结论：

```text
基础信息完整性校验 → 必填字段检查 → 业务规则校验 → 短信模板合规性检查
```

如存在必填字段缺失或规则冲突，会一并列出，便于提交前修正。

**提交配置**后，产品进入审批：

- 助手返回提交结果与**工单编号**，并提供「查看审批进度」入口；
- 右侧展示**审批抽屉**：工单编号、产品名称、状态标签，以及审批时间线——**配置已提交 → 主管审批 → 审批完成**；
- 审批进行中可执行「**催办**」，向审批人发送提醒。

## 四、产品运营助手 · 全流程交互

### 4.1 定位与运营身份

产品运营助手负责产品**上线后**的运营工作，覆盖"看数据、查异动、出方案"。其**视角由登录工号自动决定**：

- **平台运营**（联通国际）：管理**代理商 / 地区 / 套餐**；
- **代理商运营**（一级总代）：管理**个人用户 / 套餐 / 用量**。

不同工号的数据范围相互隔离，进入后的**运营视图**与可用的**对话场景**都不同。以下**先讲平台运营视角，再讲代理商运营视角**；每个视角内部，先讲视图、再讲对话场景。

### 4.2 平台运营视角

#### 4.2.1 视图：产品运营视图

「产品运营视图」是平台视角的运营看板，主要包含：

- **产品运营**：`收入总览`（报表收入 / 出账收入）→ `重点产品运营`（规模活跃 / 结构占比 / 新增 / 新增质量 / 收入渠道）→ 可**下钻至单品**（健康度、异动预警、关键运营指标）；
- **流量运营**：`流量运营全景总览`（流量池总量 / 已用 / 余量 / 使用率）→ `运营分析` 三个页签——**流量趋势 / 代理商 / 地区** → `重点运营机会`。

**视图与对话双向联动**：看板中任意数据行可点击「**让 AI 分析**」，问题自动回填至输入框并进入对话；下钻详情中的「**根因分析**」也可直接跳转对话继续分析。

#### 4.2.2 对话场景

**对话场景一 · 运营数据分析**：围绕平台经营指标（活跃 / 订购 / 收入）与流量批发（总量 / 已用 / 余量 / 使用率）做趋势解读，可按代理商 / 地区 / 套餐档位下钻。

> 帮我看下本月平台整体流量池的使用率与余量，按地区分布

返回**关键指标表（含环比）→ 归因结论 → 建议动作**，并提供「打开运营视图」「下钻」等入口。

**对话场景二 · 异动归因分析**：定位平台侧异动根因，支持四类归因（示例周期：2026 年 8 月）：

| 异动类型 | 示例数据 | 结论 |
|---|---|---|
| 套餐新增异动 | 本月新增订购 21,000 笔（上月 28,400，环比 -26.1%） | 竞争性新增萎缩 |
| 收入下滑 | 批发结算收入 24,280 万元（环比 -8.2%） | 结构性收入下滑 |
| 地区退订率上升 | 平台均值 3.6%，香港 6.8%、台湾 5.9% 偏高 | — |
| 代理商使用率异常 | 均值 57.4%，部分代理商达 69.3% | — |

输出包含**异动概览 → 核心发现 → 根因贡献度**，并附**思考过程**（解析诉求 → 锁定范围 → 拉取数据 → 定位根因 → 生成报告）与**追问入口**，支持逐层深入；可点击「查看完整版报告」，查看图表化的产品画像、趋势图与竞品对标。

> 说明：「**套餐优化建议**」不对平台视角开放（套餐组合调整属代理商侧动作）。

### 4.3 代理商运营视角

#### 4.3.1 视图：代理商运营视图

以代理商工号进入后，看板切换为代理商口径：

- **代理商运营全景总览**（个人用户）；
- **运营分析**：**个人用户 / 子渠道 / 套餐 / 成本** 四个页签。

同样支持「让 AI 分析」与对话的双向联动。

#### 4.3.2 对话场景

**对话场景一 · 运营数据分析**：围绕自身用户的活跃 / 订购 / 收入，以及自购流量的使用率与余量，可按个人用户 / 在用套餐 / 档位下钻。

> 看下我这个月自己客户的活跃变化，新增和退订多少

**对话场景二 · 异动归因分析**：定位"退订率最高的套餐 / 大客户用量骤减 / 毛利下降 / 流失预警客户群"等问题。

**对话场景三 · 套餐优化建议**：按使用率对套餐分档（🔴高负载 / 🟢利润池 / 🟡健康），给出档位升级 / 组合补位 / 留存提利 / 结构调优等动作，并测算预期收益。

> 我名下哪几档套餐需要优化，怎么调整档位更合理

### 4.4 两个视角共通：从洞察到上架（一次对话驱动的闭环）

在异动分析得出优化方案后，回复末尾提供决策入口：

> **启动产品优化（推荐） · 启动产品下线 · 暂不处理，3 天后再次提醒 · 我有问题需要确认**

点击「**启动产品优化**」后，工作台自动串联三个助手完成以下链路：

```text
① 运营助手确认方案
      ↓ 自动调用
② 查询助手核实品类与资费画像、校验互斥规则
      ↓ 自动调用
③ 研发助手匹配业务模板、预填配置、自动打开配置工作台（字段标注 已解析 / AI推荐）
      ↓
④ 智能稽核 → 提交配置（生成工单）
      ↓
⑤ 审批通过 → 即上架（产品状态更新为"已上架"）
      ↓
⑥ 归档至「我的产品（工单中心）」
```

整个过程中，右上方**流程条**实时同步进度，共三个阶段：

> **① 方案设计 —— ② 产品配置 —— ③ 审批上架**

由此，"发现一个问题"到"新版产品上架"在一个对话中即可完成，无需跨系统操作。

## 五、产品查询助手 · 全流程交互

### 5.1 场景一：智能问答

以自然语言提问，系统从**产品库**与**制度知识库**中检索作答，覆盖三类问法：

**① 产品问询**

> WeWalk-Data Only-澳门.香港.台湾共用 30 日不限量（30GB 高速）包含多少高速流量？

返回「**要点速览**」卡，高亮所问字段，并列出产品类型、高速流量、有效期、漫游地、限速策略、月费、语音、短信、套外计费、当前状态等要素。

**② 制度问询**

> 产品命名有什么规范要求？

以知识库检索方式作答，并**标注引用来源**，例如：

> 📎 引用来源：《产品命名与编码规则》· 产品管理中心规范 产管〔2025〕07 号 · 更新于 2025-11-02

**③ 档案调阅**

> 调阅"WeWalk-Data Only-澳门.香港.台湾共用 30 日不限量（30GB 高速）"的配置档案

系统在右侧打开该产品的**只读配置工作台**，包含基础信息 / 属性信息 / 资源配置 / 信息预览四个页签。存量在架产品的档案会标识为全生命周期已完成。

> **联动能力**：可查询研发助手配置的在配草稿，例如"查一下我最近配置的套餐"即会列出相关草稿，实现两个助手之间的数据贯通。

### 5.2 场景二：比对分析

输入 2～3 款产品即可生成横向比对：

> 对比 WeWalk-Data Only-澳门.香港.台湾共用 30 日不限量（30GB 高速） 和 WeWalk-Data Only-澳门.香港.台湾共用 15 日不限量（15GB 高速）

右侧打开**比对面板**，包含：

- **资费要素对比表**（高速配额 / 有效期 / 漫游地 / 网络速率 / 限速策略 / 运营数据），优势项自动高亮；
- **资源量柱状对比图**；
- **差异结论摘要**。

此外支持通过对话修改比对对象，面板实时刷新：

> "把 30 日换成 15 日"（替换） · "叠加 3GB/日高速档"（新增） · "去掉 1 日档"（移除）

## 六、全局能力

以下能力贯穿三个助手，是工作台的公共设施。

### 6.1 我的草稿

用于管理**未提交的配置草稿**，来源包括对话式配置、文件导入批量配置、存量产品复制配置。点击任一草稿可继续完善配置，提交后自动移出草稿列表。

### 6.2 我的产品（工单中心）

用于统一管理**已提交与已上架的产品**，支持按产品名称、工单编号、业务模板、销售渠道检索。对每款产品可：

- 查看只读「**配置画像**」；
- 点击「**产品运营指标**」，跳转至运营助手查看该产品的运营视图；
- 执行下架 / 恢复上架等操作。

### 6.3 消息通知与今日待办

以消息中心统一汇总两类事项：

- **我的审批**：审批中的工单，可打开审批抽屉查看进度；
- **今日待办**：按紧急程度分级（紧急·异动 / 重要·整合 / 提醒·合规），每项均可一键发起相应处理，例如点击异动项的「分析」即进入对话完成根因分析。

### 6.4 会话与输入能力

- **会话管理**：新建会话；历史对话支持按**标题 / 内容 / 工单编号**检索；支持删除会话；
- **多模态输入**：支持文件上传、图片上传、语音输入，以及拖拽与粘贴；
- **其他**：模型切换；消息支持赞同 / 不赞同 / 复制 / 重新生成；思考过程可展开查看。

## 附录 B · 术语说明

| 术语 | 说明 |
|---|---|
| 工作台（驾驶舱） | 三栏式统一入口，负责在三个助手之间调度 |
| 配置工作台 | 右侧产品配置面板，含基础信息 / 属性信息 / 资源配置 / 信息预览四个页签 |
| 智能稽核 | 提交前的自动校验，含基础信息完整性、必填字段、业务规则、短信模板四类检查 |
| 流程条 | 右上方三阶段进度：方案设计 → 产品配置 → 审批上架（审批通过即上架） |
| 字段来源标签 | 已解析（用户需求得出）/ AI 推荐（AI 依模板与相似产品补全） |
| 运营身份 | 按登录工号区分（平台运营 / 代理商运营），决定数据范围与场景 |
| 工单编号 | 配置提交后生成的唯一编号（形如 WO+日期+序号），用于追踪与归档 |
