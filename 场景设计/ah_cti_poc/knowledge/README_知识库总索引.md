## 入库操作指引（九思平台）
1. 平台知识库创建 5 个分类：K1 业务规范库 / K2 资费规则库 / K3 测试规范库 / K4 存量销售品资料库 / K5 FAQ。
2. 按分类上传对应目录下 .md 文档；K4 需逐个上传 18 份并确认切片完成（每份 13 或 2 个切片）。
3. 切片与召回参数（细化设计 4.3 节）：切片 512 token、重叠 50 token、混合检索（语义权重 0.7）、top_k 3（wf_sub_01 节点4）/ 默认 2、score 阈值 0.75、开启引用展示。
4. 上线前执行固定回归问答 3 组（如：查 900102308 套外资费 → 应命中阶梯计费描述）。
5. 重新生成 K4：修改源数据后执行 `python knowledge\gen_k4_slices.py`（源：`方案\产品信息.txt`）。
