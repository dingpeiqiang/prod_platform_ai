# 产销品命名规则（试用版）

> 分类：K1 业务规范库 | 版本：V1.0（试用版，供 AI 应用知识库冷启动使用）
> 用途：wf_sub_01 需求分析（节点2/4 知识库检索）；销售品名称校验与 AI 补全命名参照。

## 1. 产品/销售品命名模板

### 1.1 5G-A 系列套餐命名模板
```
5G-A + [融合/单品]套餐 + [档位金额]元
```
- 融合套餐：含宽带、天翼高清等融合成员，如"5G-A融合套餐199元"。
- 单品套餐：仅移动业务，如"5G-A套餐单品239元"。
- 档位金额为月基本费（元/月）。

### 1.2 权益随心选系列命名模板
```
[档位金额]元权益随心选[版本名]版
```
- 版本名枚举：娱乐 / 生活 / 出行 / 商超。
- 档位金额枚举：19.9 / 29.9（元/月）。
- 示例：19.9元权益随心选娱乐版、29.9元权益随心选出行版。

## 2. 销售品 ID 编码规则
- 销售品 ID 为 9 位数字编码，产品域统一分配，不得自造。
- 当前在售 ID 段示例：
  - 5G-A 系列：900102306~900102313、900113043~900113046
  - 权益随心选系列：900117020~900117027

## 3. 命名校验要点（稽核联动）
1. 名称与档位金额一致性：名称中金额必须与月基本费字段一致。
2. 名称与系列一致性：融合/单品/权益版本后缀必须与配置的套餐类型、权益内容一致。
3. 名称唯一性：同一在售周期内销售品名称不得重复。
4. 名称与 ID 对应关系须与产品域登记一致；AI 补全命名时必须以知识库 K4 存量资料为参照，禁止虚构 ID 与名称组合。
