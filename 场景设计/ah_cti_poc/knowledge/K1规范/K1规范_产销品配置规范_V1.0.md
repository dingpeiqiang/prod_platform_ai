# 产销品配置规范（试用版）

> 分类：K1 业务规范库 | 版本：V1.0（试用版，供 AI 应用知识库冷启动使用）
> 用途：wf_sub_01 需求分析（节点2/4 知识库检索）；为配置工作台字段定义与填写规范提供依据；wf_sub_02 智能配置字段映射参考。

## 1. 配置工作台字段定义

### 1.1 字段清单（核心）
| 字段 | 说明 | 填写规范 | 来源 |
| --- | --- | --- | --- |
| 销售品ID | 销售品唯一标识 | 9 位数字编码（如 900102308） | 原始需求 |
| 销售品名称 | 对外展示名称 | 按命名规则（见 K1《产销品命名规则》） | 原始需求 |
| 月基本费 | 套餐档位费 | 数值+单位（元/月），如 199元 | 原始需求 / AI补全 |
| 计费周期 | 周期型缴费周期 | 月 / 自然月 | 原始需求 / AI补全 |
| 国内通用流量 | 套内流量 | 数值+单位（GB） | 原始需求 / AI补全 |
| 国内语音拨打 | 套内语音分钟数 | 数值+单位（分钟） | 原始需求 / AI补全 |
| 付费方式 | 后付费/预付费 | 枚举：后付费、预付费 | 原始需求 / AI补全 |
| 支付方式 | 账单支付等 | 枚举 | 原始需求 / AI补全 |
| 流量结转 | 是否结转 | 结转 / 不结转 | 原始需求 / AI补全 |
| 副卡规则 | 是否允许、共享规则、功能费 | 文本描述 | 原始需求 / AI补全 |
| 生效方式 | 立即生效/次月生效 | 按销售品说明 | 原始需求 / AI补全 |
| 销售渠道 | 渠道范围 | 实体渠道、电子渠道、直销渠道 | 原始需求 / AI补全 |

### 1.2 字段来源与"待补充"规则（V1.4 口径，必须遵守）
- 字段来源仅允许两种枚举：**原始需求 / AI补全**。
- **仅"价格、资源"两类字段**在用户未提供且知识库无参照时填"待补充"（禁止推理、禁止编造）。
- 其余缺失字段可由 LLM 基于知识库 K4（query_similar_offer 相似产品）推理补全，来源标记"AI补全"。

## 2. 字段填写通用规范
1. 数值类字段必须带单位；金额精确到元或分（如 19.9元）。
2. 枚举类字段必须取自本文 1.1 定义的枚举值，不得自造。
3. 文本类字段描述须与《产品信息》原文一致，禁止改写业务含义。
4. 同步属性：部分销售品需增加同步属性（如 20020104）及平台编码（卫星移动运营支撑平台 1000000444、谢绝来电天翼防骚扰平台 1000000341、号百CRM系统 1000000380、天翼云盘（个人版）1000000279、爱音乐 1000000027、天翼智慧家庭 1000000345 等），按 K4 销售品文档"销售渠道"切片所列配置。

## 3. 配置执行流程规范
1. 必须先经执行方案确认（confirmed=true）后方可触发智能配置；未经确认触发将被拒绝（NOT_CONFIRMED）。
2. 配置落地前进行二次校验（confirmed 门禁 + 幂等校验），重复执行不得产生重复写入。
3. 配置完成后依次通过：实时稽核（spec/fee/all）→ 资费校准（fee/overlay/superposition/all）→ 自动测试；任一环节失败即中断主干，按异常引导处理。

## 4. 稽核与校验要点
- 稽核场景：spec（配置规格）/ fee（资费）/ all。
- 资费校验场景：fee / overlay（叠加优惠）/ superposition（超叠加）/ all。
- 告警级别：high / middle / low；high 告警必须整改后方可进入下一环节。

## 5. 附则
- 本规范为试用版，正式版以业务部门发布的《产销品配置规范》为准。
- 字段新增或口径调整时，由知识运营人员按命名规范上传新版本并删除旧版本切片。
