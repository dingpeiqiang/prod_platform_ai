# 产销品管理办法（试用版）

> 分类：K1 业务规范库 | 版本：V1.0（试用版，供 AI 应用知识库冷启动使用）
> 用途：wf_sub_01 需求分析（节点2/4 知识库检索）；为需求字段解析、上架流程判断提供依据。

## 1. 总则

### 1.1 适用范围
本规范适用于安徽电信 CPCP 产销品域内全部产销品（含销售品、资费包、权益包）的上架、变更、退订及全生命周期管理，覆盖 5G-A 系列套餐、权益随心选系列等在售产品。

### 1.2 职责分工
| 角色 | 职责 |
| --- | --- |
| 产品经理 | 发起产品/销售品需求，提供《产品信息》要素（资费、订购、变更、退订规则） |
| 市场部（业务审核） | 审核资费方案、销售策略、渠道范围的合规性 |
| 计费部门 | 审核资费结构、计费口径、叠加优惠约束 |
| IT 支撑部门 | 完成产销品配置工作台录入、实时稽核、资费校准、自动测试及上线审批 |
| 省公司 | 按省内实际情况制定副卡功能费/张数规则、宽带及天翼高清等省内配置项 |

### 1.3 上架流程（总览）
1. 需求受理：产品经理提交销售品需求（含产品信息要素）。
2. 需求分析：AI 数字员工解析需求，生成执行方案（字段清单 + 配置方案），经人工确认。
3. 智能配置：按执行方案在配置工作台完成字段录入与落地。
4. 实时稽核：对已配置内容做规格稽核（spec/fee 场景），稽核不通过须整改。
5. 资费校准：对资费做校验（fee/overlay/superposition 场景），消除资费风险。
6. 自动测试：发起销售品自动测试（受理/计费场景），生成测试报告。
7. 上线审批：测试通过后提交上线审批，审批通过方可发布在售。

## 2. 销售品生命周期管理

### 2.1 新增
- 新销售品须先在产品域完成产品定义（产品 ID、类型、依赖关系），再创建销售品配置。
- 订购当月执行过渡期资费；老用户订购次月 1 日生效（以销售品说明为准）。

### 2.2 变更
- 销售品可变更至中国电信其他在售套餐；若当前套餐已下架，变更后无法回退办理原套餐。
- 变更生效方式与老用户订购生效方式保持一致（次月 1 日生效）。

### 2.3 退订/拆机/携出
- 允许退订的，退订次月生效，退订当月费用不退还；主套餐退订时，套餐中涉及权益功能同步退订。
- 拆机次月生效，拆机当月费用不退还；携出限制以销售品说明为准（如"无携出限制"）。

### 2.4 下线
- 下线销售品资料保留 6 个月后归档（不删除，避免历史追溯断档）；在售状态以中国电信当地营业厅公示为准。

## 3. 配置与稽核要求
- 配置录入必须通过产销品配置工作台完成，禁止绕过工作流直接调用落地接口（绕过将返回 NOT_CONFIRMED）。
- 配置完成后必须依次通过实时稽核与资费校准；稽核/校验不通过的不得发起自动测试与上线审批。
- 上线审批须在执行结果确认后发起（approve_confirmed 校验），未确认发起将被拒绝。

## 4. 附则
- 本规范为试用版，正式版以业务部门发布的《产销品管理办法》为准。
- 与集团、省公司相关文件（如《关于新增5G-A 套餐相关销售品的通知》业资调度〔2025〕6号、《关于优化5G-A相关销售品的通知》业资调度〔2025〕22号）冲突时，以上级文件为准。
