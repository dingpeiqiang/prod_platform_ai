## 1. 资费结构模板

### 1.1 5G-A 系列套餐资费结构
| 结构项 | 内容 | 计费口径 |
| --- | --- | --- |
| 套餐内资费档位 | 月基本费（元/月） | 周期型缴费：月；订购当月按日折算（过渡期） |
| 套内流量 | 国内通用流量（GB） | 限中国内地使用，不含 WLAN |
| 套内语音 | 国内语音拨打分钟数；接听免费 | 限中国内地；不足1分钟按1分钟计 |
| 网络权益 | 上下行峰值速率 | 需终端支持且接入 5G-A 网络 |
| 卫星权益 | 卫星语音分钟数、短信条数 | 不足1分钟按1分钟计 |
| 套外流量 | 阶梯模式 | 前100MB 按0.03元/MB；达3元赠924MB（即3元/1GB）；超1GB后每超出1GB 按3元/1GB |
| 套外语音 | 0.15元/分钟 | 超出套内分钟数后计收；不足1分钟按1分钟计 |
| 套外短彩信 | 0.1元/条 | — |
| 套外卫星资费 | 国内/港澳台 9元/分钟；国际长途 20元/分钟；国际卫星 50元/分钟；短信 5元/条 | 不足1分钟按1分钟计；接收免费；不支持国际短信 |
| 断网授权 | 套外流量达600元暂停当月上网 | 次月初自动开通；用户申请继续则按套外资费收费 |
| 副卡 | 功能费/张数由省公司制定 | 可共享语音、流量、网速、卫星权益；应用权益不共享 |

## 2. 过渡期资费口径（5G-A 系列）
- 订购当月套餐月基本费按日（当月实际天数）计扣（入网当日到月底），费用四舍五入到分。
- 套餐内容（语音、流量）按照对应流量和分钟数按天折算，**向上取整**。

## 3. 生效口径
- 新入网用户订购立即生效，当月执行过渡期资费。
- 老用户订购次月 1 日生效，当月执行原套餐资费。
- 退订/拆机次月生效，当月费用不退还。

## 4. 资费校验（fee 场景）核对项
1. 月基本费与命名档位一致。
2. 套外流量阶梯口径：0.03元/MB → 3元/1GB（含赠送924MB 规则）。
3. 套外语音 0.15元/分钟、套外短彩信 0.1元/条。
4. 卫星套外资费四档（9/9/20/50 元/分钟）与短信 5元/条。
5. 过渡期按日折算、向上取整口径。
6. 断网授权 600元封顶暂停口径。
