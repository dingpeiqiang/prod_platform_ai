# 异常处理矩阵（自原细化设计第 7 章迁移，V2.3 口径）

> 程序执行中发生异常时，按本矩阵处置后**中断并引导**，输出模板见 SKILL.md。下表"技能N"为历史编号，对应关系：技能1→程序A、技能2/3/5/4→程序B 环节1~4、技能6→程序C、技能7/8→程序D、技能0→SKILL.md 总调度。
>
> **串行中断总则**：除明确标注"提示型异常（保留项）"的 E14/E27/E28 及脚本内置传输层重试（E29 口径，共尝试 3 次）外，任何异常一律终止当前链路并询问用户，禁止自主判断后继续执行其他环节/链路、禁止自主重试、禁止自主降级。
>
> 环节3/4 新增异常判定引用：E27 见 flow-B 环节3"desc 系统性为空处置"；E26 见 flow-B 环节4"被测一致性预校验"（先于场景覆盖核对执行）。
