#### 8. 查询测试进度（受理）

| 项目 | 内容 |
| --- | --- |
| 验证场景 | 智能测试 |
| 服务域 | 产销品域 |
| 一级服务 | 产销品数字员工服务 |
| 二级服务 | 查询测试进度（受理） |
| EOP ApiID | `ApiId:2071410624769560576` |
| 服务描述 | 轮询测试任务当前所处步骤、是否完成、是否失败；用于驱动前端步骤版 thinking |
| 服务地址 | `https://eop-ops.cloud.anhuitelecom.com:10008/api/anhui/cpcp/getTestProgress` |

**请求入参**

```text
{"globalId":"50202685110376650781903945"}
```

**响应出参**

```json
{
  "resultCode": "0",
  "resultObject": {
    "globalId": "50202685102148057375972701",
    "totalSteps": 5,
    "activeIndex": 5,
    "done": true,
    "failed": false,
    "failIndex": -1,
    "totalSceneCount": 3,
    "finishedSceneCount": 3,
    "failedSceneCount": 0
  },
  "resultMsg": "处理成功"
}
```

**核心参数解释 / 备注**

1、`globalId`（requestObject，必填）：测试流水号，取 offerTest 返回的 `resultObject.globalId`；

2、`totalSteps`（返回）：总步骤数 = 场景数 + 2，前 2 步固定为 智能匹配测试场景&用例、智能匹配测试资源，由前端推进、不占后端场景轮询位；

3、`activeIndex`（返回，从 0 计）：当前应高亮的步骤下标（总步骤下标即 totalSteps），全部成功时指向最后一步（totalSteps-1），存在失败场景时停在该失败步骤；无场景为空时 = 2（第1个场景位）；

4、`done`（返回）：测试是否全部完成；`failed`（返回）：是否存在失败/中止（RESULT_CODE='1'/'2'）场景；`failIndex`（返回）：第一个失败场景的步骤下标，无失败为 -1；

5、`totalSceneCount / finishedSceneCount / failedSceneCount`（返回）：场景总数 / 已完成场景数（终态=测完）/ 失败(含中止)场景数；场景状态映射 `obj_test_scene_rel.RESULT_CODE`（0 成功 / 1 失败 / 2 已中止 / NULL 进行中或排队）；

**核心参数解释 / 备注**

1、`globalId`（requestObject，必填）：测试流水号，取 offerTest 返回的 `resultObject.globalId`（须在测试进度全部完成后轮询本接口，结果才有完整数据）；

2、`testRequestId`（返回）：测试请求 ID（auto_test_request 表主键），本次测试批次唯一标识；`testRequestName` 测试名称（销售品系统名+_测试验证）；`orderId`/`offerInstId` 实际受理生成的订单号/销售品实例 ID；

3、`testScenes[]`（返回）：逐场景测试结果，每场景含：
- `testCaseCount` / `successTestCaseCount` / `failTestCaseCount`：测试点总数 / 成功数 / 失败数；
- `testCasePointResults[]`：测试点比对明细，字段：`testCaseName` 用例名、`testPointNbr` 测点编码（P_EFF_DATE 生效时间 / P_EXP_DATE 失效时间 / P_STATUS 实例状态 / P_MAIN_PROD 主产品构成 / P_RELY_REL 依赖关系 / P_MUTEX_REL 互斥关系 / P_ORD_CNT 订购数量 / P_OFFER_NAME 名称 / P_OFFER_TYPE 类型 / P_PAY_MODE 付费方式）、`presetValue` 规格规定值（如生失效时间配置、关系校验规定）、`testValue` 实测值（CRM 实际生成结果）、`resultCode` 是否一致（0 一致 1 不一致）、`resultMsg` 比对结论；
- `objTestSceneRel`：AI 生成的场景总结：`resultMsg` 场景测试总结、`summaryDesc` 汇总描述、`suggestion` 优化建议；

4、`offerName`（返回）：被测销售品名称；`resultCode`/`resultMsg`：接口处理结果（0 成功 / 1 失败并带失败原因）；
