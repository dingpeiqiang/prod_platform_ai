## AI应用开发（总览）

**AI应用开发**基于九思大模型，提供低代码工具，集成了智能体技术的各个环节，提供全流程工具支持，大大降低了智能体的开发难度，提高开发效率，快速构建智能体、自动化流程等应用。

### 核心功能

- **助手管理**：提供完整的助手编排页面，如开场白配置、引导问题配置、提示词配置、插件配置、知识库配置、工作流配置、大模型配置。
- **插件管理**：插件和工具是包含关系，插件管理页面提供了插件和工具的增、删、改、查能力。
- **知识管理**：将文件或FAQ上传为知识后，用户发送消息时，助手能够引用知识库中的内容回答用户的问题。
- **工作流管理**：工作流支持通过可视化的方式，对插件、大语言模型、选择器等功能进行组合，从而实现复杂、稳定的业务流程编排。

### 应用场景

- 智能问答场景
- 智能运维场景
- 售服助手场景

## 3.5.5.1 功能概述

**AI应用开发**提供了智能体编排及插件、知识库、工作流等诸多功能的创建能力，可基于提示词、插件、知识库、工作流等创建智能体。接下来首先介绍一下各个功能板块的组成以及作用：

### 智能体

| 功能 | 说明 |
| --- | --- |
| 提示词 | 提示词用于对助手的回答作出一系列指令和约束，提示词编写的越好，智能体回答的效果就越好 |
| 插件 | 插件是工具的集合，可将插件下的工具添加到智能体中，智能体可调用工具来回答用户的问题 |
| 工作流 | 工作流是预先编排好的一整套业务流程，复杂的业务流程可采用工作流的方式来解决 |
| 知识库 | 给大模型提供额外的知识，智能体可引用知识库的内容来回答用户的问题 |
| 模型配置 | 对大模型的温度值、多轮对话轮数等进行配置 |
| FAQ直接返回答案 | 基于检索到的问答对直接返回答案，不需要大模型进行归纳总结 |
| 答案为空提示 | 当智能体无法回答问题时，展示给用户的文案 |
| 开场白文案 | 进入智能体对话页面时，智能体说的第一段话 |
| 引导问题 | 进入智能体对话页面时，引导用户提问的问题 |
| 预览与调试 | 提供智能体的预览界面，可实时调试智能体 |

### 插件

| 功能 | 说明 |
| --- | --- |
| 基础信息 | 工具的基础信息，包括工具的接口地址、请求方式、工具描述、工具提示词等 |
| 输入参数 | 工具的入参信息，包括字段名称、字段描述、字段类型等 |
| 输出参数 | 工具的出参信息，包括字段名称、字段描述、字段类型等 |

### 工作流

| 功能 | 说明 |
| --- | --- |
| 基础节点 | 提供了大模型和选择器两个基础节点，用于编排工作流 |
| 插件 | 创建的插件也可用于编排工作流 |
| 工作流编排 | 采用拖拉拽及连线的方式，从业务流程的开始到结束，编排整个流程 |

### 知识库

| 功能 | 说明 |
| --- | --- |
| 知识分类 | 用于对知识库进行分类 |
| 知识列表 | 展示每个知识分类下对应的知识库列表 |
| 知识上传 | 支持上传word、pdf、FAQ等类型的文档 |

## 3.5.5.2 智能体

### 智能体介绍

- **智能体**（Agent）是一种能够感知环境、进行决策和执行动作的智能实体。它们拥有自主性和自适应性，可以依靠AI赋予的能力完成特定任务，并在此过程中不断对自我进行完善和改进。
- 传统的LLM擅长处理并生成文本，但无法联网去执行具体的操作，智能体让LLM具备了目标实现的能力，LLM充当人类的大脑，智能体接收大脑的指令调用工具完成某项操作。

### 智能体的作用

借助于智能体的高度可扩展性，可通过给智能体配置不同的知识库和插件，来解决各种领域和场景中的问题。

### 智能体创建

#### 步骤一：填写智能体的基本信息

1. 点击左侧导航栏的「助手」菜单，跳转到助手列表页面
2. 点击「创建助手」按钮，在弹窗中输入助手的基本信息：
   - 助手代码：助手的标识字段，可输入英文字母和下划线
   - 助手名称
   - 功能介绍：助手的功能介绍，200字以内
   - 发布范围：选择该助手是所有人可见还是仅自己可见
   - 排序：该助手在助手列表页的排序
   - 图标：可使用默认图标，也可单独上传图标

#### 步骤二：助手编排

1. 点击「确认」按钮后，跳转到「助手编排」页面，可在「助手编排」页面配置助手的提示词、插件、工作流、知识库等信息

2. **提示词**
   - 提示词用于对助手的回复做出一系列指令和约束，提示词可在一定程度上影响助手的回复；
   - 可采用【角色+技能+限制】的模式来编写提示词

3. **插件**
   - 点击插件旁的「+」按钮，弹窗显示可添加的插件列表
   - 选择插件下的工具，点击「添加」按钮进行添加
   - 插件添加完成后，可点击操作下的删除按钮进行删除

4. **工作流**
   - 点击工作流旁的「+」按钮，弹窗显示可添加的插件列表
   - 点击对应工作流后的「添加」按钮进行添加
   - 工作流添加完成后，可点击操作下的删除按钮进行删除

5. **知识库**
   - 点击知识库旁的「+」按钮，弹窗显示可添加的知识库列表
   - 选中对应的知识库后点击「确认」按钮进行添加
   - 知识库添加完成后，可点击操作下的删除按钮进行删除

6. **模型配置**
   - 可选择该助手所使用的大模型
   - 可配置多轮对话的轮数，最多支持20轮
   - 可配置大模型的温度值，温度值越高，答案越多样，反之，答案越严谨
   - 可配置大模型的top_k参数，top_k越高，采样集越大
   - 可配置大模型的top_p参数，top_p越小，越容易出头部
   - FAQ直接返回答案，若选择是，则会根据向量检索的结果直接返回答案，大模型不会对检索到的知识片段进行归纳总结

7. **答案为空提示**
   - 当助手无法回答用户的问题时，展示给用户的文案，可自定义编辑

8. **开场白文案**
   - 进入智能体对话页面时，智能体说的第一段话，可自定义编辑

9. **引导问题**
   - 进入智能体对话页面时，引导用户提问的问题，可自定义配置多个

#### 步骤三：调试及预览

- 助手基本信息配置完成后，点击右上角的「保存」按钮，将助手的信息保存后可在右侧的预览与调试页面对助手的效果进行调试

#### 步骤四：发布

- 助手调试完成后，点击右上角的「发布」按钮，可将助手发布到小思的页面上

## 3.5.5.3 插件

### 插件介绍

- **什么是插件**

  插件是工具的集合，也可以将插件理解为工具的分类，一个插件下可以创建多个工具，最终可将工具配置到智能体上。

- **插件的作用**

  插件可作为大模型的技能扩展，传统的大模型无法调用外部工具；将创建好的插件配置到智能体上后，在问答的过程中，智能体可调用工具解决用户的问题。

### 插件创建

#### 步骤一：创建插件

1. 点击「插件」菜单跳转插件页面，在插件页面中点击「创建插件」按钮；
2. 在弹窗中输入插件的基本信息，包括插件的名称、功能介绍、图标；
3. 点击「确认」按钮，跳转插件详情页面。

#### 步骤二：创建工具

1. 点击「新建工具」按钮，跳转工具创建页面；

2. 填写工具的基本信息：
   - 工具代码：工具的标识字段，可输入英文字母和下划线
   - 工具名称
   - 工具描述：填写工具的功能描述，方便通过向量检索来检索合适的工具回答用户的问题
   - 工具类型：url或tool
   - 接口协议：http/https、websocket
   - 接口地址：填写接口的完整地址
   - 是否归纳总结：可选是或否，若选择是，则大模型会对接口出参的内容以自然语言进行归纳总结
   - 归纳总结类型：可选LLM模型或代码解释器
   - 工具提示词：填写工具的功能描述，方便大模型通过提示词来匹配合适的工具回答用户的问题

3. 配置输入参数：
   - 参数英文名称：输入入参字段的名称，支持英文字母和下划线
   - 参数描述：描述参数的主要作用，类似于提示词，大模型会根据该提示词将自然语言转换为对应的入参字段
   - 枚举值：若该字段需要从多个值中进行选择，可填入所有的枚举值，多个值用逗号分隔
   - 为空提示：大模型无法获取该参数时给用户的提示
   - 数据类型：该字段的数据类型，包括string、int、data、float等
   - 是否必填：调用接口时该参数是否必传
   - 是否提参：是否需要大模型从用户给出的信息中提取出对应的参数
   - 默认值：该字段的默认值，目前系统提供了多个默认值，可使用{默认值名称}表示

4. 填写工具的出参：
   - 参数英文名称：输入出参字段的名称，支持英文字母和下划线
   - 参数描述：描述参数的主要作用，类似于提示词，大模型会根据该提示词将出参字段转换为自然语言
   - 数据类型：该字段的数据类型，包括string、int、data、float等
   - 是否必填：表示接口出参是否一定返回该字段

5. 保存工具：点击保存按钮，工具创建成功

#### 步骤三：发布插件

1. 在插件详情页面点击「发布」按钮；
2. 若插件下有可用的工具，则插件发布成功；若无可用的工具，会提示创建可用的工具才能发布。

### 插件使用

可将插件作为智能体的能力扩展配置到智能体中，也可将插件作为节点添加到工作流中。

**（1）在智能体中使用插件**

1. 点击左侧导航栏中的「助手」菜单，跳转到助手列表页面；
2. 点击「创建助手」按钮，填写助手的基本信息后跳转助手编排页面；
3. 在助手编排页面，点击「插件」右侧的+按钮，弹窗显示可添加的插件列表；
4. 选择插件下对应的工具进行添加。

**（2）在工作流中使用插件**

1. 点击左侧导航栏中的「工作流」菜单，跳转到工作流列表页面；
2. 点击「创建工作流」按钮，填写工作流的基本信息后跳转工作流编排页面；
3. 选择「插件」Tab，可显示已经发布的插件；
4. 可将插件下的工具拖到画布中进行编排。

## 3.5.5.4 知识库

### 知识库介绍

1. **什么是知识库**

   知识库是用户上传的外部知识的集合，同时提供了向量检索能力，可以从一定程度上解决大模型幻觉、专业领域知识不足的问题，提高大模型回答的准确率。

2. **知识库的作用**
   - 知识存储和管理：支持上传word、pdf、txt等格式的文件，上传完成后会对文档进行切片并存储到向量数据库中；用户可增加、修改、删除知识内容
   - 检索增强生成：通过关键字对向量数据库的知识内容进行向量检索，大模型会根据检索到的知识片段进行归纳总结生成最终的回复内容

### 知识库创建

#### 步骤一：创建知识分类

1. 点击左侧导航栏的「知识」菜单，跳转到知识管理页面；
2. 点击「新增」按钮，在弹窗中输入分类的名称、排序和上级分类；
3. 点击「确定」按钮，知识分类新增成功。

#### 步骤二：上传知识

1. 点击「知识列表」Tab，切换到知识列表页面
2. 点击「新增」按钮，在弹窗中选择模版
3. 可选择单FAQ模版、多FAQ模版和文档模版上传知识：
   - **单FAQ模版**：填写文档标题，并选择知识分类；填写问题和答案后点击「提交」按钮
   - **多FAQ模版**：点击「新增」按钮，可新增多个FAQ进行提交
   - **文档模版**：选择文档模版后，跳转到「知识采编」页面，可上传word、pdf、txt格式的文件，其他格式的文件陆续会支持上传；进度条到100%后，即可点击提交按钮上传文档知识

#### 步骤三：查看知识

1. 在知识列表页面点击对应的知识分类，可查看该分类下上传的知识列表

### 知识库使用

可将知识库作为智能体的外部知识配置到智能体中，在问答的过程中，智能体可引用知识库中的数据回答用户的问题。

- 点击左侧导航栏中的「助手」菜单，跳转到助手列表页面；
- 点击「创建助手」按钮，填写助手的基本信息后跳转助手编排页面；
- 在助手编排页面，点击「知识库」右侧的+按钮，弹窗显示可添加的知识库列表；
- 选择对应的知识库进行添加。

## 3.5.5.5 工作流

### 工作流介绍

- **什么是工作流**

  工作流（Workflow）通常指的是一系列定义好的步骤或任务，这些步骤或任务按照特定的顺序执行，以完成一个特定的目标或过程。

- **工作流的作用**

  工作流可以解决大模型处理复杂业务流程的不确定性问题，对于复杂业务流程，可预先编排好明确的业务流程，大模型识别到具体任务后，调用工作流，按照预先编排好的流程运行。

### 工作流创建

#### 步骤一：填写工作流基本信息

- 点击左侧导航栏的「工作流」菜单，跳转到工作流列表页面，点击「创建工作流」按钮
- 在弹窗中输入工作流的名称、描述并上传图标
- 点击「确认」按钮跳转到工作流编排页面

#### 步骤二：工作流编排

1. 可以通过拖拉拽的方式将各节点拖到画布中，并按照任务执行顺序连接各节点

2. 目前提供了四个基础节点和插件节点来编排工作流，基础节点包括：开始节点、结束节点、大模型节点、选择器节点；插件节点来源于在插件管理页面中创建的插件

3. **配置开始节点**
   - 开始节点用于开启触发一个工作流
   - 开始节点可支持一个或多个参数
   - 每个参数需输入对应的参数名称、参数类型、参数描述，并选择该参数是否必传
   - 参数名称仅支持英文字母和下划线的组合
   - 参数类型可选择string、int、date、float
   - 参数描述用于帮助大模型更好的将自然语言转换为对应的接口入参

4. **配置选择器节点**
   - 选择器节点是一个if-else节点，用于设计工作流内的分支流程
   - 当向该节点输入参数时，节点会判断是否符合如果区域的条件，符合则执行如果对应的工作流分支，否则执行否则对应的工作流分支
   - 支持添加多个判断条件（且/或）

5. **配置大模型节点**
   - 大模型节点可用于处理文本生成和自然语言理解任务
   - 设置大模型的温度值：模型生成内容的随机度。取值范围[0-1]，数值越大表示生成不确定性越高、内容越多元
   - 输入参数：可配置多个输入参数，输入参数可自定义输入也可引用之前节点的参数
   - 提示词：该节点的提示词。在提示词中支持使用引用输入参数（Input）
   - 输出参数：可配置多个输出参数，支持string、int、float、date类型，需描述该输出参数的用途，方便大模型进行识别

6. **配置结束节点**
   - 结束节点用于输出工作流的结果
   - 可配置多个输出参数，每个输出参数可自定义内容也可引用之前节点的参数
   - 大模型最终会根据输出参数归纳总结生成工作流运行的结果

7. **配置插件节点**
   - 可将创建好的插件拖动到画布中作为工作流的一个节点进行编排；
   - 插件节点下的输入参数和输出参数来源于插件管理页面的配置，输入参数可自定义值，也可引用之前节点的参数；
   - 插件节点下的输入参数和输出参数均不可新增或修改。

#### 步骤三：保存或发布

工作流编排完成后，可点击保存按钮将工作流保存为草稿，此时工作流不会发布；也可直接点击发布按钮，将工作流发布。

### 工作流使用

可将工作流作为智能体的能力扩展配置到智能体中，面对特定的复杂业务流程，智能体可调用工作流解决。

- 点击左侧导航栏中的「助手」菜单，跳转到助手列表页面；
- 点击「创建助手」按钮，填写助手的基本信息后跳转助手编排页面；
- 在助手编排页面，点击「工作流」右侧的+按钮，弹窗显示可添加的工作流列表；
- 选择对应的工作流进行添加。
