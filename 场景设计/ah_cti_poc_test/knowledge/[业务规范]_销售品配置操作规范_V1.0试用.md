[业务规范] 销售品配置操作规范（试用版 V1.0）

> 说明：知识库冷启动试用版，供 CPCP 配置操作与规格稽核使用，需与系统实际配置项核对后转为正式版。

一、配置总体流程

1. 需求确认 → 2. CPCP 产品主数据配置 → 3. CRM 侧配置 → 4. 计费侧配置 → 5. 一致性自查 → 6. 提交规格稽核 → 7. 资费校准 → 8. 测试 → 9. 上线审批

二、CPCP 产品主数据配置项

2.1 必填配置项清单
| 配置项 | 类型 | 校验规则 |
| --- | --- | --- |
| product_id | string | 全局唯一，格式 P+10位数字 |
| product_name | string | 符合命名规范，≤30字符，目录内唯一 |
| product_type | enum | 基础套餐/增值包/优惠活动/政企定制 |
| parent_id | string | 挂载到正确的产品目录节点 |
| effect_date | date | ≥当日，且早于 expire_date |
| expire_date | date | 默认 2099-12-31，退市品为实际日期 |
| sale_province | string | 默认 anhui，跨省需审批标记 |
| status | enum | draft/online/offline，初始 draft |

2.2 规格关系配置
1. 互斥关系：定义不可同时订购的产品清单（写入 exclude_list）；
2. 依赖关系：定义前置必订产品（写入 require_list），如副卡依赖主套餐；
3. 组合关系：融合套餐需关联其子产品清单。

三、CRM 侧配置项

3.1 产品目录与属性
| 配置项 | 校验规则 |
| --- | --- |
| 目录挂载 | 与 CPCP 目录一致，禁止挂错节点 |
| 受理界面展示 | 名称、资费、生效期展示与需求书一致 |
| 订购属性 | 是否允许新订/续订/退订、是否重复订购 |
| 用户群限制 | 与需求书销售范围一致（新入网/存量/携转） |
| 渠道限制 | 与需求书渠道清单一致，默认全渠道开放需说明 |

3.2 订购关系
1. 与主套餐的绑定关系必须配置（增值包必须可挂到在售主套餐）；
2. 退订规则：月末退订/即时退订需明确，默认月末生效；
3. 变更规则：档位变更（升级/降级）的生效方式需配置。

四、计费侧配置项

4.1 基础计费配置
| 配置项 | 校验规则 |
| --- | --- |
| 月租费 | 与需求书一致，支持按天分摊（default）或整月收取（需注明） |
| 一次性费用 | 开通费/手续费，可减免需配置减免规则 |
| 超套单价 | 按 GB/分钟/条定义，与需求书一致 |
| 计费周期 | 自然月（默认），跨月处理规则明确 |
| 生效方式 | 立即生效/次月生效，与受理侧一致 |

4.2 优惠配置
1. 优惠规则编码遵循 OF+4位序号；
2. 每条优惠必须声明适用产品范围与互斥清单；
3. 折扣率与减免金额不得同时生效于同一计费事件。

五、一致性自查项（配置完成后、提交稽核前）

1. product_id 三侧一致（CPCP/CRM/计费）；
2. product_name 三侧一致；
3. 资费金额三侧一致（重点核对月租与超套单价）；
4. 生效/失效时间三侧一致；
5. 销售范围与用户群 CRM 与 CPCP 一致。

六、常见配置错误与预防（稽核高频问题）

| # | 错误 | 预防措施 |
| --- | --- | --- |
| 1 | CRM 资费金额与需求书不一致 | 配置后回读比对，数字员工自动核对 |
| 2 | 生效时间填成过去日期（如上线当天 00:00 前的时间） | 稽核规则：effect_date ≥ 提交日 |
| 3 | 目录挂载到已退市节点 | 配置前查询父节点状态 |
| 4 | 互斥关系漏配导致叠加漏洞 | 依据资费互斥清单逐条核对 |
| 5 | 增值包未配置可订购主套餐范围 | 必填 require_list |
| 6 | 计费周期与受理展示口径不一致 | 三侧一致性自查 |

七、配置数据格式约定（供数字员工生成配置使用）

7.1 CRM 配置数据（crm_config_json）核心字段
{
  "product_id": "P20260001",
  "product_name": "流量包-畅享5G通用包-30GB-24个月",
  "product_type": "增值包",
  "parent_catalog": "CATL_FLOW_001",
  "sale_scope": {"province": "anhui", "channel": ["营业厅","APP","网厅"], "user_group": ["新入网","存量"]},
  "order_rule": {"new": true, "renew": true, "cancel": "month_end", "repeat": false},
  "effect_date": "2026-10-01",
  "expire_date": "2099-12-31"
}

  "fee": {"monthly": 29.0, "once": 0, "over_price": {"unit": "GB", "price": 3.0}},
  "billing_cycle": "natural_month",
