[资费规则] 资费规则与优惠叠加互斥清单（试用版 V1.0）

> 说明：知识库冷启动试用版，作为资费校准环节（check_billing_rule）规则依据，需计费部门确认后转正式版。

一、基础资费规则

1.1 计费基本规则
1. 计费周期默认自然月（1 日 0 时至月末 24 时）；
2. 月中订购按天分摊月租，分摊公式：月租 × 剩余天数 ÷ 当月自然天数，四舍五入到分；
3. 月中退订：增值包当月月租照收、权益可用至月末；基础套餐变更次月生效；
4. 超套部分按产品配置单价计费，不足一个计费单位按一个单位计。

1.2 生效规则
| 类型 | 默认生效 | 说明 |
| --- | --- | --- |
| 新订购增值包 | 次月生效 | 可选立即生效（当月按天分摊） |
| 档位变更（升级） | 立即生效 | 差额按天补收 |
| 档位变更（降级） | 次月生效 | 防止套利 |
| 退订 | 月末生效 | 权益使用至月末 |
| 合约产品 | 立即生效 | 在约期内限制退订 |

1.3 资费红线（禁止项）
1. 禁止负资费（计费金额为负）；
2. 禁止零元月租长期产品（免费体验类需限定 ≤3 个月并自动转常规资费）；
3. 禁止资费倒挂（同档位短期合约总价高于长期合约）；
4. 禁止超套单价低于套内单价的 50%（防套利）；
5. 单产品折扣后金额不得低于成本红线的 70%（政企定制需特批）。

二、优惠叠加规则

2.1 叠加基本约束
1. 同一计费要素（流量/语音/短信）上，同类型优惠（折扣类）最多叠加 1 个；
2. 减免金额类与折扣率类优惠不得同时作用于同一计费事件；
3. 合约类优惠（终端补贴、话费返还）与体验类优惠（免费体验）不得叠加；
4. 优惠叠加后实际资费不得低于该产品的最低保护价。

2.2 互斥清单（示例，需按现行政策维护）
| 互斥组 | 规则 | 说明 |
| --- | --- | --- |
| G01 | 流量畅享包 与 流量加油包 | 同为通用流量，只能订其一 |
| G02 | 限时5折活动 与 首充返现活动 | 两类价格优惠不可同时享受 |
| G03 | 合约终端补贴 与 0元体验包 | 补贴期内禁止叠加免费品 |
| G04 | 存量升级礼包 与 新入网礼包 | 按用户群二选一 |
| G05 | 政企团购折扣 与 个人端促销折扣 | 渠道属性互斥 |

2.3 依赖与前置
1. 副卡产品必须依赖主套餐（require：主套餐在订）；
2. 权益包（视频会员类）必须绑定基础套餐 V2 档及以上；
3. 国际漫游包必须实名且无欠费用户方可订购。

五、典型资费错误案例（用于校验规则回归）

案例1：双重折扣
某包配置 8 折优惠（OF0001）且同时配置立减 10 元（OF0005），未互斥 → 叠加后月租 29×0.8-10=13.2 元，低于保护线。整改：二选一或配置互斥。

案例2：退订仍计费
退订生效配置为"次月"，但计费侧优惠截止日为当月末 → 用户退订后次月被收取优惠差额。整改：优惠有效期与订购关系联动。

案例3：超套套利
套内 30GB/29 元（折算 0.97 元/GB），超套单价 0.5 元/GB → 用户故意超额套利。整改：超套单价 ≥ 套内折算单价。

案例4：月末订购整月收费
生效方式误配"立即生效+整月收取" → 31 日订购收整月 29 元。整改：改为按天分摊。
